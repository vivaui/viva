v0.6.3 是 v0.6.2 之后的 patch 版本：修复 Windows 旧系统上的单实例启动、macOS 输入法组合、表格滚动条与提示框绘制等问题，并新增固定列、表格横向滚动、虚线边框、可调列宽与网页视图回调等一批可选 API 与能力，已有 API 不变，升级不需要改调用点。macOS 是参考平台。

v0.6.3 is a patch release after v0.6.2: it fixes single-instance startup on older Windows systems, input-method composition on macOS, table scrollbars and tooltip painting, and adds a set of opt-in APIs and capabilities, including frozen columns, horizontal table scrolling, dashed borders, resizable columns and web view callbacks. Existing APIs are unchanged, so upgrading needs no call-site edits. macOS is the reference platform.

## 拿到它 · Getting it

`go get github.com/vivaui/viva@v0.6.3`，需要 Go 1.26 或更新；系统依赖与 v0.6.2 相同。每个 Release 附带 `viva` 命令的预编译压缩包、`SHA256SUMS`，以及 Homebrew 与 Scoop 清单（`brew install vivaui/tap/viva`，或 `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` 后 `scoop install viva`）；压缩包没有代码签名或公证，浏览器下载的 macOS 版会被 Gatekeeper 拦下，brew、curl 与 `go install` 不受影响。

`go get github.com/vivaui/viva@v0.6.3` needs Go 1.26 or newer; the system requirements are those of v0.6.2. Every Release carries prebuilt archives of the `viva` command, `SHA256SUMS`, and Homebrew and Scoop manifests (`brew install vivaui/tap/viva`, or `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` then `scoop install viva`); the archives are not code-signed or notarized, so a browser download on macOS is stopped by Gatekeeper while brew, curl and `go install` are not affected.

## 有什么 · What is in it

- Windows 的单实例认领改用每用户命名管道，Windows 10 1803 之前与 Windows Server 2016 可以正常启动，认领失败时的错误会带上平台给出的原因
- `Box.TextEnd()` 现在也把 `Input`、`TextField` 的文字放到行尾，聚焦时的光标、选区与平台编辑器保持同一边
- 空的 `CodeEditor` 也绘制光标行的底色，与有内容的编辑器一致
- `TableSpec.HideHoverScrollbars` 让应用自己绘制垂直滚动条时不再叠加表格的匿名悬停条
- 提示框的长文本按可见区域换行，不再套用八行省略预算，未断开的文件名可以完整显示
- `TableSpec.FrozenColumns` 把左侧若干列固定在原地，横向滚动时它们与表头一起保持可见
- `SetClipboardHTML(html, alt)` 在一次写入中放入 HTML 与纯文本两种格式，浏览器里通过 `SetClipboardHTMLAsync` 返回 Promise
- 自绘表格的横向滚动条落在为它保留的 gutter 里，不再盖住最下面一行
- 虚线边框通过 `Box.Dashed()`、`Look.Dashed(bool)` 与 `DrawContext.DashedBorder` 使用
- `InputSnapshot.Alignment` 让字段的文字、光标、选区与平台编辑器在聚焦时保持同一对齐
- `gfx.PointerCursorGrabbing` 在 macOS、Wayland/X11、Web 与 Windows 上都有对应的抓取光标
- `PathStyle.Dashed` 与 `Canvas.DashedRoundedOutline` 通过路径管线绘制虚线轮廓，闭合轮廓按整周期收口，热画布不分配
- 宽表格可以横向滚动：固定的表头随列移动，`TableSpec.HorizontalScrollbar` 指定表体下方的滚动条，`TableState.Scroll` 报告两轴的偏移与视口，Shift+滚轮横向移动列
- `TableState.RowID` 与 `TableState.Rows` 暴露上次绘制中每一行的身份与范围，应用可以按行的身份而不是行号处理指针
- 框线与块元素字形按字体自身的下划线厚度绘制，opencode 的提示边框不再随显示缩放退化成细线
- `Window.SetSize` 与 `ContentWindow.SetSize` 请求原生窗口内容尺寸，headless driver 同样支持，不支持的主机返回 `ErrUnsupported` (contributed by @Ezreal-byte) (PR [#172](https://github.com/vivaui/viva/pull/172))
- 自定义标题栏的 macOS 交通灯可以通过 `TrafficLightScale` 缩放 (contributed by @imjakey) (PR [#254](https://github.com/vivaui/viva/pull/254))
- `WebViewConfig.Proxy` 设为 `WebProxyDirect` 时该页面绕过系统代理 (contributed by @imjakey) (PR [#253](https://github.com/vivaui/viva/pull/253))
- `Box.TooltipOn(side)` 让提示框在指定的一边打开，`TooltipSide` 与四个方向常量随包导出 (contributed by @xiaoyumuxi) (PR [#252](https://github.com/vivaui/viva/pull/252))
- 菜单行只在指针不在菜单内其它控件上时绘制当前项底色，应用不必再为嵌入控件做绘制期的焦点绕行
- `ColorSwatch.Flush()` 让色块填满边框内的圆
- macOS 在输入法组合期间更新文本输入布局时不再丢弃已输入的拼音
- 提示框箭头改成一个按设备像素羽化的三角形，100% 与 125% 缩放下不再出现粗糙台阶
- Windows 的 `FileIcon` 返回系统图标，文本文件与未知类型不再共用同一个图标 (contributed by @Zer0ON1) (PR [#249](https://github.com/vivaui/viva/pull/249))
- `components.BeginColumnResize` 提供可拖动的表格列宽，支持最小宽度与按内容贴合 (contributed by @Zer0ON1) (PR [#247](https://github.com/vivaui/viva/pull/247))
- `WebViewConfig.Ephemeral` 让网页视图的数据留在临时存储里，不写入持久化目录 (contributed by @1lck) (PR [#244](https://github.com/vivaui/viva/pull/244))
- `WebViewConfig.Navigate`、`NewWindow` 与 `Download` 让应用在导航、弹窗和下载发生前先做决定，`WebNavigation` 说明是哪个 frame 发起的 (contributed by @1lck) (PR [#243](https://github.com/vivaui/viva/pull/243))
- 网页视图的顶部圆角由 `TopCornerRadius` 设置，光标由原生视图自己维护 (contributed by @imjakey) (PR [#248](https://github.com/vivaui/viva/pull/248))
- `OpenDirectoryPath` 返回用户选择的一个现有目录，取消时返回 `ErrCanceled`
- `CodeEditorSnapshot.GutterMarkers` 在行号旁的行内绘制并暴露可点击的标记区，`CodeEditorGutterMarker` 的 `ID` 由调用方处理点击
- Linux 与 Windows 的构建固定 `CGO_ENABLED=0`，在 Ubuntu 上构建的 Linux 程序不再携带构建机的 glibc，可以在更旧的发行版上启动
- 重新生成 scroll-area、tooltip 与 code-editor 的组件安装模板，组件生成器的检查重新通过

- Windows claims single-instance ownership at a per-user named pipe, so Windows 10 before 1803 and Windows Server 2016 start normally, and a failed claim reports the platform's reason
- `Box.TextEnd()` now places an `Input` or `TextField`'s text at the end of its line, including the caret, selection and platform editor while focused
- An empty `CodeEditor` now tints the caret's row like a populated one
- `TableSpec.HideHoverScrollbars` lets an application that paints its own vertical bar omit the table's anonymous hover overlay
- Tooltips wrap a long label to the visible area instead of the eight-line ellipsizing budget, so an unbroken filename stays whole
- `TableSpec.FrozenColumns` pins the leftmost columns while the table scrolls sideways, keeping them and the header visible
- `SetClipboardHTML` writes an HTML flavour beside a plain-text one in a single copy, and `SetClipboardHTMLAsync` answers through the browser's Promise
- A self-scrolling table's horizontal bar lands in its reserved gutter instead of covering the last visible row
- Dashed borders are available as `Box.Dashed()`, `Look.Dashed(bool)` and `DrawContext.DashedBorder`
- `InputSnapshot.Alignment` keeps a field's line, caret, selection and platform editor on the same alignment while focused
- `gfx.PointerCursorGrabbing` gives macOS, Wayland/X11, the web and Windows a grabbing cursor
- `PathStyle.Dashed` and `Canvas.DashedRoundedOutline` stroke dashed outlines through the path pipeline, closing whole dash periods and allocating nothing on a warm canvas
- A wide table scrolls sideways under its fixed header, with `TableSpec.HorizontalScrollbar` naming the bar below the body, `TableState.Scroll` reporting both axes, and Shift+wheel moving the columns
- `TableState.RowID` and `TableState.Rows` expose the identity and scope of the rows the last paint drew, so pointers can be handled by row identity instead of index
- Box-drawing and block glyphs now use the font's own underline thickness, so opencode's prompt border no longer thins out with display scale
- `Window.SetSize` and `ContentWindow.SetSize` request a native content size, including under the headless driver, and report `ErrUnsupported` on hosts without it (contributed by @Ezreal-byte) (PR [#172](https://github.com/vivaui/viva/pull/172))
- macOS traffic lights in a custom titlebar scale through `TrafficLightScale` (contributed by @imjakey) (PR [#254](https://github.com/vivaui/viva/pull/254))
- `WebViewConfig.Proxy` set to `WebProxyDirect` bypasses the system proxies for that page (contributed by @imjakey) (PR [#253](https://github.com/vivaui/viva/pull/253))
- `Box.TooltipOn` opens a tooltip on a chosen side, with `TooltipSide` and its four constants exported beside it (contributed by @xiaoyumuxi) (PR [#252](https://github.com/vivaui/viva/pull/252))
- A menu row draws its current-item tint only when the pointer is not over another control inside the menu, so applications no longer need a paint-time focus workaround
- `ColorSwatch.Flush()` lets a swatch fill the circle inside its border
- macOS keeps the input method's composition across text-input layout updates instead of discarding the pinyin being typed
- The tooltip arrow is one triangle feathered over a device pixel, so it stays clean at 100% and 125% scaling
- `FileIcon` returns Windows' own system icons, so a text file and an unknown file no longer look the same (contributed by @Zer0ON1) (PR [#249](https://github.com/vivaui/viva/pull/249))
- `components.BeginColumnResize` adds draggable table column widths with minimums and content-fit (contributed by @Zer0ON1) (PR [#247](https://github.com/vivaui/viva/pull/247))
- `WebViewConfig.Ephemeral` keeps a web view's data in an ephemeral store instead of the persistent one (contributed by @1lck) (PR [#244](https://github.com/vivaui/viva/pull/244))
- `WebViewConfig.Navigate`, `NewWindow` and `Download` let the application decide before a navigation, popup or download happens, with `WebNavigation` naming the frame (contributed by @1lck) (PR [#243](https://github.com/vivaui/viva/pull/243))
- A web view's top corners round through `TopCornerRadius`, and the native view owns its cursor (contributed by @imjakey) (PR [#248](https://github.com/vivaui/viva/pull/248))
- `OpenDirectoryPath` returns one existing directory the user picked, or `ErrCanceled` when they cancel
- `CodeEditorSnapshot.GutterMarkers` paints per-line markers in a lane beside the line numbers and exposes each marker's `ID` as a button the caller handles
- Linux and Windows builds pin `CGO_ENABLED=0`, so a Linux program built on Ubuntu no longer carries the builder's glibc and starts on older distributions
- The scroll-area, tooltip and code-editor component installation templates are regenerated, so the component generator checks pass again

## 注意 · Caveats

- 本版使用 patch 版本号，但包含新增 API；没有删除或改变已有导出 API，升级不需要迁移
- Windows 上，改动前构建的副本用 Unix socket 认领、改动后构建的副本用命名管道，两者互不相认；升级时让旧进程全部退出后再启动新版本即可
- Linux 与 Windows 的 `viva build` 固定 `CGO_ENABLED=0`，应用自带的 cgo 代码在这两个平台上需要改为纯 Go 或系统调用

- This release uses a patch version number but adds APIs; no existing exported API is removed or changed, so no migration is needed
- On Windows a copy built before this change claims at a Unix socket while one built after claims at a named pipe, so they do not meet; exit every old process before starting the new build
- `viva build` pins `CGO_ENABLED=0` for Linux and Windows, so application code that uses cgo on those targets needs pure Go or system calls instead
