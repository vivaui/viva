v0.6.5 是 v0.6.4 之后的 patch 版本：修复 Linux 上窗口出现前投递的工作丢失、Windows 更新下载与替换、文本输入组合与剪贴板等问题，并新增 `Application.Post`、应用自有的 macOS 菜单栏、原子文件保存、上下文菜单定位、系统代理读取、防止休眠与 RPM 包等能力。macOS 是参考平台。升级需要注意一处行为变化，见"注意 · Caveats"。

v0.6.5 is a patch release after v0.6.4: it fixes work posted before the first Linux window being lost, Windows update download and replacement, and text composition and clipboard issues, and adds `Application.Post`, an application's own macOS menu bar, atomic file saves, context menus at captured points, system proxy reading, sleep prevention and RPM packages. macOS is the reference platform. One behaviour change needs a look before upgrading; see "注意 · Caveats".

## 拿到它 · Getting it

`go get github.com/vivaui/viva@v0.6.5`，需要 Go 1.26 或更新；系统依赖与 v0.6.4 相同。每个 Release 附带 `viva` 命令的预编译压缩包、`SHA256SUMS`，以及 Homebrew 与 Scoop 清单（`brew install vivaui/tap/viva`，或 `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` 后 `scoop install viva`）；压缩包没有代码签名或公证，浏览器下载的 macOS 版会被 Gatekeeper 拦下，brew、curl 与 `go install` 不受影响。

`go get github.com/vivaui/viva@v0.6.5` needs Go 1.26 or newer; the system requirements are those of v0.6.4. Every Release carries prebuilt archives of the `viva` command, `SHA256SUMS`, and Homebrew and Scoop manifests (`brew install vivaui/tap/viva`, or `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` then `scoop install viva`); the archives are not code-signed or notarized, so a browser download on macOS is stopped by Gatekeeper while brew, curl and `go install` are not affected.

## 有什么 · What is in it

- `Application.Post` 把工作从任意 goroutine 交给拥有窗口的事件循环线程，按投递顺序执行，不额外启动 goroutine 或定时器。
- `Application.SetMenuBar` 为应用安装自己的 macOS File、Edit、View 菜单，快捷键、勾选、子菜单与动作都在循环线程上派发。
- `document` 包的 `Read` 与 `Save` 原子地读写文件并返回 SHA-256 版本，`Changed` 报告文件是否已被其他程序改动。
- `ContextMenuAt` 在画布单元格、表头和编辑器这类没有命中目标的位置打开上下文菜单，并在窗口边缘夹住，不翻到指针另一侧。
- `PreventSleep` 在应用需要时阻止系统空闲休眠：macOS 用 IOKit 断言，Windows 用电源请求，Linux 用 logind 抑制器。
- `SystemProxy` 报告桌面为某个 HTTP 地址选择的代理；需要时导入 `app/proxy`，不使用的应用不会链接它的网络栈。
- `gfx.FitLineMiddle` 截断长文本时保留两端，适合路径这类末尾相同、差异在中间的文本。
- `TreeItem.Dragging` 与 `TreeState.DragSource` 标出被拖动的行和指针位置，拖放到行上与行间各有可见的位置标记。
- `Styles` 让页面一处替换按钮、复选框、开关和文本输入的外观；菜单可以声明 `Unpainted`，由页面自己绘制面板与行，键盘与焦点行为不变。
- 双击选中单词、三击选中整行，拖动时按单位扩展选区；`text.LineRange` 给出这一行的范围。
- `viva package --format rpm` 生成 Fedora、RHEL 与 openSUSE 的 `.rpm`；`--cgo` 为原生包启用 cgo 构建。
- 文本输入的组合阶段可以按需开启，macOS、Windows、Linux 的 IBus 与 GTK 都会发出阶段事件，应用可以拿到组合所有权。
- Windows 上可以分别选择界面字体与等宽字体的字重。
- Windows 剪贴板保留列选择的元数据，粘贴到表格类目标时能还原列。
- 应用可以让系统在传输等工作期间保持唤醒，由应用决定哪些工作需要它。

- `Application.Post` runs work from any goroutine on the thread that owns the windows, in the order it was accepted, without starting a goroutine or timer.
- `Application.SetMenuBar` installs the application's own File, Edit and View menus on macOS; shortcuts, check marks, submenus and actions dispatch on the loop thread.
- `Read` and `Save` in the `document` package write files atomically and return a SHA-256 revision; `Changed` reports whether another program has changed the file.
- `ContextMenuAt` opens a context menu at a point the application captured, such as a canvas cell, a column header or an editor, and clamps it at the window edge instead of flipping it to the other side of the pointer.
- `PreventSleep` keeps the machine awake while the application needs it: an IOKit assertion on macOS, a power request on Windows and a logind inhibitor on Linux.
- `SystemProxy` reports the proxy the desktop selects for an HTTP URL; import `app/proxy` for it, so an application that does not ask for a proxy does not link the network stack.
- `gfx.FitLineMiddle` shortens a long line by keeping both ends, for paths whose difference is in the middle.
- `TreeItem.Dragging` and `TreeState.DragSource` mark the carried row and the pointer, and drops into a row or between rows each have a visible mark.
- `Styles` lets a page replace the button, checkbox, switch and text-entry looks in one place; a menu can be declared `Unpainted`, so the page paints its panel and rows while keyboard and focus behaviour stay the same.
- Double-click selects a word and triple-click a line, and a drag extends the selection by that unit; `text.LineRange` returns the line range.
- `viva package --format rpm` writes `.rpm` packages for Fedora, RHEL and openSUSE; `--cgo` enables cgo for native packages.
- Text composition phases can be turned on per input, and IBus, GTK, Windows and macOS emit them, so an application can take composition ownership.
- On Windows the interface and fixed-pitch font weights can be chosen separately.
- The Windows clipboard keeps column selection metadata, so a table paste target can restore the columns.
- An application can keep the machine awake while work such as a file transfer needs it; the application decides which work that is.

## 注意 · Caveats

- `KeyEvent.Text` 不再把 Shift 应用到字符上：Control+Shift+C 的 `Text` 现在是 `"c"`，按下的修饰键放在 `Modifiers` 中。依赖大写 `Text` 的代码需要改为读取 `Modifiers`。
- 超出条目范围的列表键现在会 panic，这是对调用方错误的显式检查。

- `KeyEvent.Text` no longer applies Shift to the character: Control+Shift+C now carries `"c"`, and the held modifiers are in `Modifiers`. Code that reads an uppercase `Text` should read `Modifiers` instead.
- A list key outside the item range now panics, as an explicit check on a caller's error.
