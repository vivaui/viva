v0.6.2 是 v0.6.1 之后的 patch 版本：修复同一张位图在多处绘制、且它前面的图片进出画面时，标签纹理可能被误判为已经上传、导致 macOS 窗口在重绘中关闭的问题；没有 API 变化，升级不需要改调用点。macOS 是参考平台。

v0.6.2 is a patch release after v0.6.1: it fixes a case where, with one bitmap drawn in several places and the images before it entering or leaving the frame, a label's texture could be treated as already uploaded, closing a macOS window during a repaint. No API changes, so upgrading needs no call-site edits. macOS is the reference platform.

## 拿到它 · Getting it

`go get github.com/vivaui/viva@v0.6.2`，需要 Go 1.26 或更新；系统依赖与 v0.6.1 相同。每个 Release 附带 `viva` 命令的预编译压缩包、`SHA256SUMS`，以及 Homebrew 与 Scoop 清单（`brew install vivaui/tap/viva`，或 `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` 后 `scoop install viva`）；压缩包没有代码签名或公证，浏览器下载的 macOS 版会被 Gatekeeper 拦下，brew、curl 与 `go install` 不受影响。

`go get github.com/vivaui/viva@v0.6.2` needs Go 1.26 or newer; the system requirements are those of v0.6.1. Every Release carries prebuilt archives of the `viva` command, `SHA256SUMS`, and Homebrew and Scoop manifests (`brew install vivaui/tap/viva`, or `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` then `scoop install viva`); the archives are not code-signed or notarized, so a browser download on macOS is stopped by Gatekeeper while brew, curl and `go install` are not affected.

## 有什么 · What is in it

- 修复同一张位图多处绘制、其前面的图片进出画面时标签丢失纹理的问题，macOS 上不再因此关闭窗口并报 `darwin: failed to rebuild a text label`

- Fixes labels losing their texture when one bitmap is drawn in several places and the images before it enter or leave the frame, which on macOS closed the window with `darwin: failed to rebuild a text label`

## 证据在哪 · Where the evidence is

- 发布门禁覆盖 `gofmt`、`go vet ./...`、`go test ./... -count=1`、`-tags vivahead` 的 darwin 与 headless vet，以及 windows/linux 双架构与 js/wasm 的交叉 vet
- 在 macOS 真实窗口中用 960x620 小窗口大幅滚动复现了修复前的窗口关闭与 `darwin: failed to rebuild a text label`，修复后的同一路径不再出现；`app` 的回归测试逐帧固定了位图像素与标签位置的对应关系

- The release gate covers `gofmt`, `go vet ./...`, `go test ./... -count=1`, the `-tags vivahead` darwin and headless vet, and cross-vet for both windows/linux architectures and js/wasm
- A real macOS window at 960x620 scrolling hard reproduced the pre-fix close with `darwin: failed to rebuild a text label`, and the same path no longer failed after the fix; a regression test in `app` pins the correspondence between bitmap pixels and label places frame by frame

## 注意 · Caveats

- 本版是 patch 版本，没有新增、删除或改变导出 API

- This is a patch release; no exported API is added, removed or changed
