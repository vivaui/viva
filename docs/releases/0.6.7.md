v0.6.7 是 v0.6.6 之后的版本：主题控件全面改由引擎驱动，Image 支持圆角与透明度，Progress 能被辅助技术识别；另有多项平台修复、输入法支持与性能改进。macOS 是参考平台。

v0.6.7 comes after v0.6.6: themed controls are driven by the engine, images take a corner radius and opacity, and a labelled progress bar reaches assistive technology, alongside platform fixes, input-method support and performance work. macOS is the reference platform.

## 拿到它 · Getting it

`go get github.com/vivaui/viva@v0.6.7`，需要 Go 1.26 或更新；系统依赖与 v0.6.6 相同。每个 Release 附带 `viva` 命令的预编译压缩包、`SHA256SUMS`，以及 Homebrew 与 Scoop 清单（`brew install vivaui/tap/viva`，或 `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` 后 `scoop install viva`）。

## 有什么 · What is in it

- 主题控件（`ui.Button`、`ui.Badge`、`ui.Toggle`、`ui.Tabs`、`ui.Select`、`ui.Checkbox`、`ui.Switch`）的默认外观由配方和元素属性决定，`.Pad`、`.Gap`、`.FontSize`、`.Color`、`.Radius`、`.Children` 等现在与普通元素一致生效，控件自身的勾、滑块、轨道和箭头保持不变。
- `ui.Button` 可以用 `Children` 放调用方内容，按钮的身份、焦点、禁用、命中与键盘行为仍留在按钮上。
- `ui.Tabs` 的 `Pad` 现在作用于四边，`PadX`、`PadY` 和不对称内边距会移动触发器；`TabIconOnly()` 让标签页只画图标，标签文字仍是它的无障碍名。
- `ui.Table` 可以用 `.FontSize` 和 `.Color` 直接设置表头与单元格文字，`ui.Checkbox` 的显式 `Size` 会缩放方框和勾，`ui.Switch` 的 `FillWidth` 与 `WidthPercent` 可以拉伸轨道。
- `ui.Image` 的 `Radius` 会裁剪图片圆角，`Opacity` 会淡化图片，在 CPU、Metal、Vulkan、WebGL、Web Canvas2D 与 D3D11 六条渲染路径上都生效，且是绘制期属性、不重建纹理。
- 给了 `Label` 的 `ui.Progress` 会作为只读进度条暴露给辅助技术（0–100，indeterminate 时不报数字），不命名时仍只是装饰。
- `ui.ButtonGroup` 支持只有图标的动作与选中态，公开按钮组可以直接组合工具栏动作。
- `ui.Canvas.LabelHighlighted` 在成形文本后面按大小写不敏感匹配高亮搜索词，原文本和无障碍名保持不变。
- `WebView` 新增 `Title()`、`CanGoBack()`、`CanGoForward()`、`IsLoading()`，并提供分好类的加载失败原因。
- `app.StartFileDrag` 在 Windows 上可以把文件从窗口拖出到其他程序；`app.OpenDragPreview` 提供跟随指针的半透明预览窗口（X11 上已实现）。
- `Window.SetIcon` 可以在运行时替换窗口图标，并同步 Windows 任务栏的分组资源。
- Windows 上彩色终端行的一次绘制合并为每遍一次 GDI 调用，DirectWrite 的文本格式与布局会在光栅器生命周期内复用，滚动彩色输出更顺畅。
- Windows 的实时缩放改由定时器驱动，拖动窗口边缘时画面按自己的节奏重绘，不再被每条原生消息带着走。
- Windows 上通过消息窗口投递的唤醒不会再被模态循环吞掉，打开状态栏菜单或对话框时后台工作不会挂起。
- Linux 的 X11 后端加入 Fcitx 4 输入法支持，Sogou 等 Fcitx 4 桌面能正常上屏和显示预编辑文本。
- 带外边距的列表行现在计入滚动内容高度，最后几行可以完整滚进视野；列表滚轮偏移也会夹在已测量的范围内。
- 很长的单行文本改为从纹理窗口分段绘制，超长行不再被截断或画错。
- X11 激活窗口时带上服务端时间戳，点击窗口能正确置顶并获得焦点。
- 打开对话框时，滚轮不再传给对话框背后、被焦点陷阱挡住的列表。
- 颜色选择面板在对话框内会画在对话框之上，控件可见且可以点击。
- `ui.Select` 会先测量图标再测量标签，自动宽度的下拉触发器不再裁掉标签。
- macOS 上从 Finder 打开注册过的文档类型会送到 `OnOpenFile`；非 UTF-8 的文本标签会替换为 U+FFFD，不再导致窗口关闭。
- 方形线帽延伸到开放路径的端点之外，描边端点不再缺一截；抓取光标不可用时回退为手形指针。
- Linux 的 `.deb`、RPM 与 PKGBUILD 推荐 `libxcb-cursor`，HiDPI 桌面上的指针不再明显偏小。

- The default look of the themed controls (`ui.Button`, `ui.Badge`, `ui.Toggle`, `ui.Tabs`, `ui.Select`, `ui.Checkbox`, `ui.Switch`) comes from their recipes and the element's attributes: `.Pad`, `.Gap`, `.FontSize`, `.Color`, `.Radius` and `.Children` now work on them as on any other element, while the control's own check, thumb, track and chevron stay as they are.
- `ui.Button` takes caller content through `Children` and keeps the button's identity, focus, disabled state, hit area and keyboard behavior.
- `ui.Tabs` applies `Pad` to all four sides, so `PadX`, `PadY` and uneven padding move the triggers; `TabIconOnly()` paints icons without labels while the label stays the tab's accessible name.
- `ui.Table` styles its header and cells with `.FontSize` and `.Color`, an explicit `Size` on `ui.Checkbox` scales the box and its mark, and `FillWidth` and `WidthPercent` on `ui.Switch` stretch the track.
- `ui.Image` cuts its corners with `Radius` and fades with `Opacity` on all six renderers (CPU, Metal, Vulkan, WebGL, Web Canvas2D and D3D11), and both are draw-time values that do not rebuild a texture.
- A `ui.Progress` with a `Label` is a read-only progress bar to assistive technology (0–100, no number while indeterminate); an unnamed bar stays decorative.
- `ui.ButtonGroup` supports icon-only actions and a selected action, so a page composes toolbar actions with the public button group.
- `ui.Canvas.LabelHighlighted` paints case-insensitive search matches behind shaped text while the original text and its accessible name stay unchanged.
- `WebView` reports `Title()`, `CanGoBack()`, `CanGoForward()` and `IsLoading()`, and exposes classified load failures.
- `app.StartFileDrag` drags files out of a window to other programs on Windows; `app.OpenDragPreview` offers a translucent preview following the pointer (implemented on X11).
- `Window.SetIcon` replaces the window icon at run time and keeps Windows taskbar grouping resources in step.
- On Windows a colored terminal row is drawn with one GDI call per pass and DirectWrite formats and layouts are kept for the rasterizer's lifetime, so scrolling colored output is smoother.
- Windows live resize is paced by its timer, so dragging a window edge redraws at its own rate instead of once per native message.
- A wake posted through its message-only window is no longer swallowed by a modal loop, so background work does not hang while a status menu or dialog is open.
- The Linux X11 backend supports Fcitx 4, so desktops such as Sogou on Fcitx 4 compose and show pre-edit text.
- Rows with vertical margins now count toward a list's scrollable content, so the last rows scroll fully into view, and the list wheel offset stays within the measured extent.
- Very long single lines are drawn from windows of their texture instead of being clipped or misdrawn.
- X11 activation carries the server timestamp, so clicking a window raises it and gives it the focus.
- The wheel no longer reaches lists behind a focus trap while a dialog is open.
- A color picker inside a dialog paints its panel above the dialog, so its controls are visible and clickable.
- `ui.Select` measures its icon before its label, so an auto-sized trigger no longer clips the label.
- On macOS a registered document opened from Finder reaches `OnOpenFile`, and text labels with invalid UTF-8 are replaced with U+FFFD instead of closing the window.
- Square line caps extend past an open contour's end, and a missing grabbing cursor falls back to a hand.
- The Linux `.deb`, RPM and PKGBUILD recommend `libxcb-cursor`, so the pointer is not conspicuously small on HiDPI desktops.

## 注意 · Caveats

- `Frame.Progress(fraction)` 现在是 `Frame.Progress(ID, fraction)`；直接调用 `base.Frame` 的代码要补上身份，`ui.Progress(c, fraction)` 不变。
- dev 构建会拒绝在某个元素上不生效的通用属性并给出原因；release 构建仍与以前一样忽略它们。用 `VIVA_ATTR_CHECK=warn` 可以只报告不中断，便于一次清理整页。
- 一些以前静默无效的属性现在生效，页面外观可能变化：`Tabs` 的 `Pad` 四边都算、`PadY(0)` 不再回落到主题高度，`Checkbox` 的 `Size` 缩放方框本身，`Switch` 的宽高缩放轨道，`Image` 的 `Radius` 和 `Opacity` 会真正裁剪与淡化。

- `Frame.Progress(fraction)` is now `Frame.Progress(ID, fraction)`; code calling `base.Frame` directly must pass an identity, while `ui.Progress(c, fraction)` is unchanged.
- A dev build rejects a generic attribute that does nothing on its element and says why; release builds keep ignoring it as before. `VIVA_ATTR_CHECK=warn` reports without stopping, which helps clean a page in one pass.
- Some attributes that were silently ignored now take effect and can change a page's look: `Tabs` pads all four sides and `PadY(0)` no longer falls back to the theme height, `Checkbox.Size` scales the box itself, `Switch` width and height scale the track, and `Image.Radius` and `Opacity` really cut and fade the picture.
