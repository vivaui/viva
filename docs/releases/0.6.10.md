v0.6.10 是 v0.6.9 之后的版本：加入原生窗口水印、由应用事件循环接管的系统通知激活、跨平台麦克风采集，以及窗口装饰的即时切换；输入、剪贴板与绘制方面修复了 Caps Lock、被平台夺走的按下、Windows 与 GTK 的文件拖放回调、细描边亮度不均、静止指针下的悬停刷新等问题。macOS 是参考平台。

v0.6.10 comes after v0.6.9: native window watermarks, system notification activation owned by the application event loop, cross-platform microphone capture and live window decoration changes arrive, and input, clipboard and painting gain fixes for Caps Lock, a press the platform takes away, file-drop callbacks on Windows and GTK, uneven thin-stroke brightness and hover under a stationary pointer. macOS is the reference platform.

## 拿到它 · Getting it

`go get github.com/vivaui/viva@v0.6.10`，需要 Go 1.26 或更新；系统依赖与 v0.6.9 相同。每个 Release 附带 `viva` 命令的预编译压缩包、`SHA256SUMS`，以及 Homebrew 与 Scoop 清单（`brew install vivaui/tap/viva`，或 `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` 后 `scoop install viva`）。

## 有什么 · What is in it

- `Config.Watermark`、`Window.SetWatermark` 与 `CapabilityWindowWatermark` 在画布和内嵌原生视图（例如 web view）上方叠一层不接收输入的文字水印：macOS 用原生视图叠加，Windows 用点击穿透的分层弹窗，Linux 忽略，headless 只记录状态；自定义 host 可实现可选的 `SetWatermark(app.Watermark)`；`gfx.WeightLight` 补上细字重 (contributed by @darrenjindai) (PR [#462](https://github.com/vivaui/viva/pull/462))。
- `Application.ShowNotification` 返回可在任意 goroutine 关闭的句柄，`OnActivate` 与 `OnError` 回调排到应用事件循环上执行，点击通知即可恢复或打开窗口，`Close` 撤回通知，权限被拒时报告 `ErrPermissionDenied`；macOS 用 UNUserNotificationCenter，Windows 用唤醒窗口上的托盘气泡，其他平台返回 `ErrUnsupported`，`CapabilityNotificationActivation` 报告平台是否支持 (contributed by @darrenjindai) (PR [#475](https://github.com/vivaui/viva/pull/475))。
- `audio.OpenInput` 从默认输入设备采集 16 位小端 PCM，`Input` 实现 `io.ReadCloser`；macOS 用 CoreAudio，Windows 用 WASAPI，Linux 用 ALSA，其他平台返回 `ErrInputUnsupported`；macOS 的麦克风授权与 bundle 键见 `docs/audio.md` (contributed by @DeanCen) (PR [#483](https://github.com/vivaui/viva/pull/483))。
- `Window.SetDecorated` 在已显示的窗口上切换原生装饰，并在确认后通过 `done` 报告一次结果。
- 窗口可以让控件声明自己的指针光标，指针悬停时跟随命中项的光标图片，状态项在原生悬停时可预览；菜单项可以加字母助记键；`TextArea` 在 `Secure` 时把内容显示为圆点；剪贴板可以放入承诺文件；被省略的标签悬停时显示全文，只读文本可在 `TextSelectionArea` 中选择并复制。
- 新增 `ui/overflowlist`（折进「更多」菜单的工具栏行）、统计、输入标签、自动补全与指示器控件；`CodeEditor` 增加跟随编辑的折叠状态、可点击的折叠省略徽标、行号栏与字节装饰。
- `gfx` 可以在设备像素上绘制调用方的位图，`HitOptions` 有了 `IsZero`；颜色选择器的无效 HEX 提示已本地化；headless 脚本可以把复制的文件放上剪贴板。
- 细描边在三角形与裁剪之间保持均匀覆盖：竖直细线与被裁剪的图标描边不再沿长度方向忽明忽暗 (contributed by @mirakyux) (PR [#488](https://github.com/vivaui/viva/pull/488))。
- 布局变化后，静止的指针下的控件在同一帧得到悬停与光标，菜单不会因此丢掉键盘的当前行 (contributed by @mirakyux) (PR [#487](https://github.com/vivaui/viva/pull/487))。
- 工具提示在获得焦点的控件没有 `Hint` 时回退到悬停；被应用处理的 Tab 不再显现键盘焦点 (contributed by @DeanCen) (PR [#481](https://github.com/vivaui/viva/pull/481))。
- 无填充按钮的焦点环画成光晕而不是盖满表面，`viva add button` 与 `button-group` 装出的代码与参考组件一致 (contributed by @caichangqing1120) (PR [#484](https://github.com/vivaui/viva/pull/484))。
- Caps Lock 作为按键交给应用；被平台夺走的按下会正常结束；页面按一格滚动时使用区域自己的屏幕。
- Windows 监听的目录被移走并在原路径重建时，现在会报告 Resync (contributed by @1lck) (PR [#485](https://github.com/vivaui/viva/pull/485))；Windows 在首帧前应用显示器的 DPI，`WindowNotification` 的原点以物理像素报告 (contributed by @Ezreal-byte) (PR [#479](https://github.com/vivaui/viva/pull/479))，并在 Windows 与 GTK 上保护文件拖放回调 (contributed by @Ezreal-byte) (PR [#480](https://github.com/vivaui/viva/pull/480))。
- Windows 在注册字体里绘制回退字形，且剪贴板事务固定在同一个系统线程上；Linux 读取放下选择时带上 `XdndDrop` 时间戳，字体列表包含双宽与未标记的等宽字体，门户的初始目录得到转发。
- Web 与 dev 构建恢复了光标图片回调 (contributed by @caichangqing1120) (PR [#477](https://github.com/vivaui/viva/pull/477))；增量渲染的混合删除与插入不再重建整页，批处理的临时空间在页面缩小后释放，每次绘制只对已发布的命中区域比较一次。
- `viva init` 与 `viva add` 的组件模板已按源码重新生成。

- `Config.Watermark`, `Window.SetWatermark` and `CapabilityWindowWatermark` lay a text watermark over the canvas and over embedded native views such as a web view, without taking input: macOS uses a native overlay view, Windows a click-through layered popup, Linux ignores it, and headless only records the state; a custom host may implement the optional `SetWatermark(app.Watermark)`, and `gfx.WeightLight` adds a light weight (contributed by @darrenjindai) (PR [#462](https://github.com/vivaui/viva/pull/462)).
- `Application.ShowNotification` returns a handle closable from any goroutine; its `OnActivate` and `OnError` callbacks run on the application event loop, so a click can restore or open a window, `Close` withdraws the notification, and a refused permission is reported as `ErrPermissionDenied`; macOS uses UNUserNotificationCenter, Windows a tray balloon on the wake window, other targets return `ErrUnsupported`, and `CapabilityNotificationActivation` reports whether the platform has it (contributed by @darrenjindai) (PR [#475](https://github.com/vivaui/viva/pull/475)).
- `audio.OpenInput` captures 16-bit little-endian PCM from the default input device, and `Input` implements `io.ReadCloser`; macOS uses CoreAudio, Windows WASAPI and Linux ALSA, and other targets return `ErrInputUnsupported`; the macOS microphone permission and bundle keys are in `docs/audio.md` (contributed by @DeanCen) (PR [#483](https://github.com/vivaui/viva/pull/483)).
- `Window.SetDecorated` toggles native decorations on a shown window and reports the confirmed result once through `done`.
- A control can declare its own pointer cursor, the pointer follows a hit's cursor picture, a status item can be previewed on native hover, menu items take letter mnemonics, a `TextArea` shows its value as bullets when `Secure`, promised files can be put on the clipboard, an ellipsized label shows its full text on hover, and read-only text can be selected and copied in a `TextSelectionArea`.
- New are `ui/overflowlist` (a toolbar row that folds into a More menu) and statistic, input tag, autocomplete and indicator controls; `CodeEditor` gains edit-following fold state, a clickable ellipsis badge on folded lines, a gutter and byte decorations.
- `gfx` draws a caller's bitmap on device pixels and `HitOptions` has an `IsZero`; the color picker's invalid HEX message is localized; and a headless script can put copied files on the clipboard.
- A thin stroke keeps uniform coverage across triangles and clips: a thin vertical line or a clipped icon stroke no longer brightens and dims along its length (contributed by @mirakyux) (PR [#488](https://github.com/vivaui/viva/pull/488)).
- After a layout change the control under a stationary pointer takes hover and cursor in the same frame, and menus keep the keyboard's current row (contributed by @mirakyux) (PR [#487](https://github.com/vivaui/viva/pull/487)).
- A tooltip falls back to hover when the focused control has no `Hint`, and a Tab the application handled no longer shows keyboard focus (contributed by @DeanCen) (PR [#481](https://github.com/vivaui/viva/pull/481)).
- An unfilled button's focus ring is drawn as a halo rather than covering its surface, and `viva add button` and `button-group` install what the reference components draw (contributed by @caichangqing1120) (PR [#484](https://github.com/vivaui/viva/pull/484)).
- Caps Lock reaches the application as a key, a press the platform takes away ends cleanly, and a page notch scrolls by the region's own screen.
- A watched directory on Windows that is moved away and recreated at the same path now reports a Resync (contributed by @1lck) (PR [#485](https://github.com/vivaui/viva/pull/485)); Windows applies the monitor's DPI before the first frame and reports the `WindowNotification` origin in physical pixels (contributed by @Ezreal-byte) (PR [#479](https://github.com/vivaui/viva/pull/479)), and file-drop callbacks are guarded on Windows and GTK (contributed by @Ezreal-byte) (PR [#480](https://github.com/vivaui/viva/pull/480)).
- Windows draws fallback glyphs from registered fonts and keeps clipboard transactions on one OS thread; Linux passes the `XdndDrop` timestamp when it reads the drop selection, lists dual-width and unflagged monospace fonts, and forwards the initial directory to the portal.
- The Web and dev builds have their cursor image callbacks back (contributed by @caichangqing1120) (PR [#477](https://github.com/vivaui/viva/pull/477)); incremental rendering applies mixed deletes and inserts without a rebuild, batch scratch is released once the page shrinks, and each paint diffs its hits against the published ones once.
- The component templates `viva init` and `viva add` install are regenerated from the sources.

## 注意 · Caveats

- 没有不兼容的 API 变更。
- 在 macOS 上使用 `audio.OpenInput` 的应用必须在 bundle 中声明 `NSMicrophoneUsageDescription`（`[mac.info]`），启用 hardened runtime 时还要在 `[mac] entitlements` 指向的文件中加入 `com.apple.security.device.audio-input`；缺少时系统可能终止进程或交付静音，而 `OpenInput` 仍报告成功。
- 水印与通知激活没有在 Linux 上实现；Windows 的水印叠加层 z 序与真机验收尚未验证。

- There are no incompatible API changes.
- An application that calls `audio.OpenInput` on macOS must declare `NSMicrophoneUsageDescription` in its bundle (`[mac.info]`) and, under the hardened runtime, `com.apple.security.device.audio-input` in the file `[mac] entitlements` names; without them the system may terminate the process or deliver silence while `OpenInput` still reports success.
- Watermarks and notification activation are not implemented on Linux; the Windows watermark overlay's z-order and real-device behaviour are not yet verified.
