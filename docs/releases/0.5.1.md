v0.5.1 是 v0.5.0 之后的 patch 版本：公开 API 只有新增，没有删除或改签名，升级不需要改调用点。本版新增 Windows、macOS 与 X11 的原生全局快捷键，加强 HierarchyMenu 在窗口边缘与窄窗口中的表现，让代码编辑器可以显示缩进参考线和软换行标记，并修复窗口缩放、文字布局、托盘菜单与 GTK 文件剪贴板上的问题。macOS 是参考平台。

v0.5.1 is a patch release after v0.5.0: the public API only gains members, with no removal or signature change, so upgrading needs no call-site edits. It adds native global shortcuts for Windows, macOS and X11, makes HierarchyMenu hold up at window edges and in narrow windows, lets the code editor show indent guides and soft-wrap markers, and fixes problems with window resizing, text layout, tray menus and the GTK file clipboard. macOS is the reference platform.

## 拿到它 · Getting it

`go get github.com/vivaui/viva@v0.5.1`，需要 Go 1.26 或更新；系统依赖与 v0.5.0 相同。每个 Release 附带 `viva` 命令的预编译压缩包、`SHA256SUMS`，以及 Homebrew 与 Scoop 清单（`brew install vivaui/tap/viva`，或 `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` 后 `scoop install viva`）；压缩包没有代码签名或公证，浏览器下载的 macOS 版会被 Gatekeeper 拦下，brew、curl 与 `go install` 不受影响。

`go get github.com/vivaui/viva@v0.5.1` needs Go 1.26 or newer; the system requirements are those of v0.5.0. Every Release carries prebuilt archives of the `viva` command, `SHA256SUMS`, and Homebrew and Scoop manifests (`brew install vivaui/tap/viva`, or `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` then `scoop install viva`); the archives are not code-signed or notarized, so a browser download on macOS is stopped by Gatekeeper while brew, curl and `go install` are not affected.

## 有什么 · What is in it

- 新增 `app.GlobalShortcut`、`app.RegisterGlobalShortcut` 与 `Driver.PressGlobalShortcut`，应用可以在 Windows、macOS 与 X11 上注册窗口失焦时也生效的全局快捷键
- Added `app.GlobalShortcut`, `app.RegisterGlobalShortcut` and `Driver.PressGlobalShortcut`, so an application can register a global shortcut that works while its window is unfocused on Windows, macOS and X11
- 新增 `app.MenuItem.ID`，Linux 托盘菜单在标题或状态变化后仍能找到同一个菜单项
- Added `app.MenuItem.ID`, so the Linux tray menu still reaches the same entry after its title or state changes
- 新增 `SingleSelectOption.Search`，单选框的查询可以匹配行里不显示的文字，例如地址或分组
- Added `SingleSelectOption.Search`, so a single select's query can match text the row does not show, such as an address or a group
- 新增 `HierarchyMenuAction` 与 `HierarchyMenuOptions` 的 `Leading`、`Trailing`、`Typeahead`，分层菜单可以在根级放置独立命令，并可选地按输入跳转
- Added `HierarchyMenuAction` and the `Leading`, `Trailing` and `Typeahead` options of `HierarchyMenuOptions`, so a hierarchy menu can carry independent root commands and optionally jump to rows as the user types
- 新增 `CodeEditor` 的 `ShowIndentGuides` 与 `ShowWrapSymbol`，代码编辑器可以显示缩进参考线和软换行行尾标记
- Added the `ShowIndentGuides` and `ShowWrapSymbol` options of `CodeEditor`, so the code editor can show indent guides and end markers on soft-wrapped rows
- 修复 HierarchyMenu 靠近窗口边缘时飞出框来回翻边、盖住上一级，现在整条级联固定在同一侧，窗口过窄时改为单面板加返回按钮
- Fixed HierarchyMenu fly-outs flipping sides at the window edge and covering their ancestors: a cascade now stays on one side, and a narrow window shows one panel with a back button
- 修复 HierarchyMenu 悬停时父级行被挪动，按下时指针下已是子菜单，现在列宽在悬停前预留
- Fixed HierarchyMenu moving a parent row while hovering, which left the child menu under the pointer at press; column widths are now reserved before any hover
- 修复拖动窗口边缘缩放时画面被拉伸
- Fixed the frame being stretched while a window is resized by dragging its edge
- 修复 Windows ARM64 上 Direct2D 文字起点错位
- Fixed Direct2D text origins on Windows ARM64
- 修复 Windows 版本 4 状态图标上标准提示不显示
- Fixed the standard tooltip not showing on Windows version 4 status icons
- 修复 macOS 上宽文字跨过 Metal 纹理边界时被截断
- Fixed wide labels being cut where they cross a Metal texture boundary on macOS
- 修复等宽文字与字体实际度量的字符单元不对齐，终端文字不再偏离单元
- Fixed monospaced labels not aligning with the font's measured character cells, so terminal text no longer drifts off its cells
- 修复无头布局检查使用的文字宽度与实际绘制不一致
- Fixed headless layout checks using text widths that differed from the painted ones
- 修复 Drawer 滑入时不平滑、标签脱离内容
- Fixed the Drawer slide not being smooth and its labels detaching from the content
- 修复原生文字覆盖层没有跟随命中区域移动
- Fixed native text overlays not moving with their hit area
- 修复网页目标中输入框文字、光标与剪切的不同步
- Fixed the text, caret and cut of a field falling out of step on the web target
- 修复 GTK 文件剪贴板在缺少写入能力时没有返回 Linux 的 `ErrUnsupported`
- Fixed the GTK file clipboard not returning Linux's `ErrUnsupported` when file-list writes are unavailable
- 修复 `viva package` 生成 DMG 时按设备而不是挂载点分离磁盘映像，卸载不再因挂载点失效而失败
- Fixed `viva package` detaching the disk image by device rather than by mount point when building a DMG, so detaching no longer fails when the mount point stops resolving
