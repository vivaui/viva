v0.4.0 是 v0.3.1 之后的 minor 版本，含一处不兼容改动：`flex.Box.HoverBackground` 已删除，改用 `Hover(flex.Look{}.Background(c))`，其余公开 API 只有新增。本版给 `flex.Box` 加上悬停、按下、聚焦三种状态外观（`Hover`、`Pressed`、`Focus`、`StateFrom`、`Transition`）以及 `Ring`、`Opacity`、`Gradient`、`GradientStops`，`ui` 新增多色渐变填充，代码编辑器补上闪烁光标、多光标与离散选区，应用层新增窗口置顶与带复选框的原生保存对话框，并附带一组带测试的组件配方供编码助手参照。macOS 是参考平台。

v0.4.0 is a minor release after v0.3.1 with one incompatible change: `flex.Box.HoverBackground` is removed in favour of `Hover(flex.Look{}.Background(c))`; the rest of the public API only gains members. It gives `flex.Box` hover, pressed and focus looks (`Hover`, `Pressed`, `Focus`, `StateFrom`, `Transition`) plus `Ring`, `Opacity`, `Gradient` and `GradientStops`, adds a multi-stop gradient fill to `ui`, gives the code editor a blinking caret, multiple carets and disjoint selections, adds always-on-top windows and native save dialogs with a checkbox to the app layer, and ships a set of tested component recipes for coding agents to copy. macOS is the reference platform.

## 拿到它 · Getting it

`go get github.com/vivaui/viva@v0.4.0`，需要 Go 1.26 或更新；系统依赖与 v0.3.1 相同，只有显示系统网页的应用需要对应的网页组件，只有选用 GTK 外壳（`-tags vivagtk`）的应用需要系统的 GTK 3。每个 Release 附带 `viva` 命令的预编译压缩包、`SHA256SUMS`，以及 Homebrew 与 Scoop 清单（`brew install vivaui/tap/viva`，或 `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` 后 `scoop install viva`）；压缩包没有代码签名或公证，浏览器下载的 macOS 版会被 Gatekeeper 拦下，brew、curl 与 `go install` 不受影响。

`go get github.com/vivaui/viva@v0.4.0` needs Go 1.26 or newer; the system requirements are those of v0.3.1, and only an application that shows web pages needs the matching web component and only one that opts into the GTK shell (`-tags vivagtk`) needs the system's GTK 3. Every Release carries prebuilt archives of the `viva` command, `SHA256SUMS`, and Homebrew and Scoop manifests (`brew install vivaui/tap/viva`, or `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` then `scoop install viva`); the archives are not code-signed or notarized, so a browser download on macOS is stopped by Gatekeeper while brew, curl and `go install` are not affected.

## 升级 · Upgrading

把 `Box.HoverBackground(c)` 改写为 `Box.Hover(flex.Look{}.Background(c))`，没有别的调用点需要改。

Replace `Box.HoverBackground(c)` with `Box.Hover(flex.Look{}.Background(c))`; no other call site needs to change.

## 有什么 · What is in it

- 删除 `flex.Box.HoverBackground`，由 `Hover(Look)` 取代
- 新增 `flex.Look`，只列出相对静止态变化的部分（`Background`、`Border`、`Color`、`Ring`、`Shadow`、`Opacity`），配合 `Box.Hover`、`Pressed`、`Focus` 声明悬停、按下与键盘聚焦时的样子，多个外观按 Focus、Hover、Pressed 逐字段合并
- 新增 `Box.Transition` 与 `TransitionWith`，在外观之间按主题动效渐变，静止时不安排任何帧；`Box.StateFrom` 让子元素跟随容器的状态
- 新增 `Box.Ring`，在元素外侧画一圈不占布局空间的环，用作焦点环
- 新增 `Box.Opacity`，让元素及其内部的控件一起淡化，仍参与布局与点击
- 新增 `Box.Gradient` 与 `GradientStops`，以及 `flex.ToRight`、`flex.ToBottomRight` 等方向常量，画在 `Background` 之上、`Border` 之下
- 新增 `ui.Canvas.FillGradient` 与 `ui.GradientStop`，多色、可指定角度、带圆角的线性渐变，预热后不分配
- 新增 `ui.Canvas.ElevateFaded` 与 `ui.Theme.WithOpacity`，淡化的元素连阴影与内部控件的颜色一并淡化
- 新增 `components.CaretBlink`，以及 `CodeEditorSnapshot` 与 `CodeDiffSnapshot` 的 `CaretWidth`、`CaretColor`，光标可闪烁并自定宽度与颜色；零值保持原来的细线，`Canvas.HasClock` 让没有帧时钟的场合不再请求帧
- 新增 `components.CodeEditorCaret`、`ExtraCarets`、`SelectionRanges` 与 `CodeEditor.OffsetWithVirtualAt`，代码编辑器支持多光标与离散选区
- 新增 `app.Window.SetAlwaysOnTop` 与 `AlwaysOnTop`，窗口可以置顶
- 新增 `app.SaveFileWithCheckbox`，原生保存对话框可带一个复选框，选择结果同时给出路径与勾选状态；`Driver` 提供对应的排队与读取方法供测试使用
- 新增 `ui.Canvas.RasterizeText`、`ui.TextRasterizer` 与 `ui.GaussianBlurBitmap`，可把文字按比例栅格化为位图并做高斯模糊
- 新增 `app.Editor` 与 `app.TextInput` 的 `Alignment`，原生输入框按对齐方式摆放而不移动输入法的候选窗位置
- 新增 `examples/recipes`，九个带测试的完成品组件（设置行、带悬停操作的列表行、带在线点的头像、徽标、统计卡、渐变横幅、图标按钮、空状态、可整体变暗的分组），以及 `building-with-viva` 技能里的 `recipes.md` 指南
- 修复代码编辑器未设置光标颜色时光标完全透明，改为回退到文字颜色
- 修复代码编辑器的字形与平台文本服务重复绘制，预览中出现两份错位的文字
- 修复包裹后的省略行每次重绘都会分配字符串，占位符比输入框更宽时尤其明显
- 修复无头驱动在输入法组字时按回车会在预编辑里插入换行，现在提交候选
- 修复 macOS 在输入框获得焦点时吞掉功能键，现在交给应用
- 修复 macOS 原生全屏窗口快捷键没有绑定

- Removed `flex.Box.HoverBackground`, replaced by `Hover(Look)`
- New `flex.Look`, which lists only what differs from rest (`Background`, `Border`, `Color`, `Ring`, `Shadow`, `Opacity`), with `Box.Hover`, `Pressed` and `Focus` declaring how an element looks under the pointer, held down and keyboard-focused; looks combine field by field in the order Focus, Hover, Pressed
- New `Box.Transition` and `TransitionWith` fade between the looks over the theme's motion and schedule no frames while at rest; `Box.StateFrom` makes a child follow its container's state
- New `Box.Ring` draws a line around the outside of an element without taking layout room, for a focus ring
- New `Box.Opacity` fades an element and the controls inside it, which stay laid out and clickable
- New `Box.Gradient` and `GradientStops`, with direction constants such as `flex.ToRight` and `flex.ToBottomRight`, painted over `Background` and under `Border`
- New `ui.Canvas.FillGradient` and `ui.GradientStop`: a multi-stop, angled, rounded linear gradient that allocates nothing once warm
- New `ui.Canvas.ElevateFaded` and `ui.Theme.WithOpacity`, so a faded element fades its shadow and the colors of the controls inside it
- New `components.CaretBlink`, and `CaretWidth` and `CaretColor` on `CodeEditorSnapshot` and `CodeDiffSnapshot`: the caret blinks and takes a width and color; zero keeps the earlier hairline, and `Canvas.HasClock` lets a widget with no frame clock ask for no frame
- New `components.CodeEditorCaret`, `ExtraCarets`, `SelectionRanges` and `CodeEditor.OffsetWithVirtualAt`: the code editor supports multiple carets and disjoint selections
- New `app.Window.SetAlwaysOnTop` and `AlwaysOnTop` keep a window above the others
- New `app.SaveFileWithCheckbox`: a native save dialog can carry a checkbox, and the result gives the path and the checked state; `Driver` has matching queue and read methods for tests
- New `ui.Canvas.RasterizeText`, `ui.TextRasterizer` and `ui.GaussianBlurBitmap` rasterize text proportionally into a bitmap and blur it
- New `Alignment` on `app.Editor` and `app.TextInput`, so a native input is aligned without moving the input method's candidate window
- New `examples/recipes`: nine tested finished components (settings row, list row with a hover action, avatar with presence dot, badge, stat card, gradient hero, icon button, empty state, dimmable section), and the `recipes.md` guide of the `building-with-viva` skill
- Fixed the code editor's caret being fully transparent when no caret color was set; it now falls back to the text color
- Fixed the code editor's glyphs being drawn twice, once by the platform text service, which showed two offset copies of the text in a preview
- Fixed a wrapped line's ellipsis allocating a string on every repaint, most visible when a placeholder is wider than its field
- Fixed the headless driver inserting a line break into a composition on Return; it now commits the candidate
- Fixed macOS swallowing function keys while a field is focused; they now reach the application
- Fixed the native macOS fullscreen window shortcut not being bound
