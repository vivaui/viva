v0.6.9 是 v0.6.8 之后的版本：组件目录补上一批页面级组件（步骤条、描述列表、时间线、评分、数字输入、日期与时间选择、穿梭框、警告条、标签、面包屑、卡片、空状态、结果页、分页、气泡确认、可关闭标签条、上传、图片预览、@ 提示、新手引导、锚点目录与评论），页面控件补上环状与分段进度、按钮与开关的忙碌态、表格的列标题与排序筛选勾选、文本计数与系统编辑菜单；加入系统拖入与拖出文件、Windows 与 Linux 的透明窗口合成、系统验证，以及可中断的弹簧与位移动画，并修复大量 Linux、Windows 与 macOS 的输入、剪贴板和绘制问题。macOS 是参考平台。

v0.6.9 comes after v0.6.8: the component catalog gains a set of page-level packages (a step bar, a labelled-values list, a timeline, a star rating, a number field, date and time pickers, a two-list transfer, an alert, a tag, a breadcrumb, a card, an empty state, a result page, a pagination row, a popconfirm, an editable tab strip, an upload area, an image preview, mentions, a guided tour, an anchor table of contents and comments), the page controls gain ring and segmented progress, busy buttons and switches, table column titles with sorting, filtering and checking, text counting and the system's own edit menu; files drag into and out of a window, Transparent windows composite on Windows and Linux, system authentication arrives, and interruptible spring motion joins the element tree, with many Linux, Windows and macOS input, clipboard and painting fixes. macOS is the reference platform.

## 拿到它 · Getting it

`go get github.com/vivaui/viva@v0.6.9`，需要 Go 1.26 或更新；系统依赖与 v0.6.8 相同。每个 Release 附带 `viva` 命令的预编译压缩包、`SHA256SUMS`，以及 Homebrew 与 Scoop 清单（`brew install vivaui/tap/viva`，或 `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` 后 `scoop install viva`）。

`go get github.com/vivaui/viva@v0.6.9` needs Go 1.26 or newer; the system requirements are those of v0.6.8. Every Release carries prebuilt archives of the `viva` command, `SHA256SUMS`, and Homebrew and Scoop manifests (`brew install vivaui/tap/viva`, or `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` then `scoop install viva`).

## 有什么 · What is in it

- `ui/steps`、`ui/descriptions`、`ui/timeline`、`ui/rate`、`ui/inputnumber`、`ui/datepicker`、`ui/timepicker` 与 `ui/transfer` 是可选的页面包，用页面自己的原语搭建，跟随页面的主题与密度。
- `ui/alert`、`ui/tag` 与 `ui/result` 用共享的 `ui.Status`（default、success、warning、danger）表示结果；`Theme.Warning` 与 `WarningColor` 补上警告色，手工构造且没有设它的主题回退到危险色。
- `ui/card` 是带可选页眉（标题、说明与末尾插槽）与页脚、紧凑尺寸和扁平形式的卡片；`ui/empty` 把图标、标题、可换行的说明与下一步操作居中。
- `ui/breadcrumb` 把路径上更早的位置做成链接，`Max` 非零时把中间的层级折进一个省略号菜单；`ui/pagination` 从总数和 `State` 自己拼出页码、上一页与下一页、总数、每页条数与跳转。
- `ui/popconfirm` 在被按下的按钮旁问一句，在交付按下的那一帧报告 `Confirmed` 或 `Cancelled`，Escape 与外部按下不回答；`ui/editabletabs` 是每个标签按标题宽度、带关闭与新增按钮、超出宽度会滚动并保持活动标签可见的标签条。
- `ui/upload` 是带系统选择器按钮的拖放区，每个文件一行状态、进度、重试与移除，控件只报告 `Added`、`Rejected`、`Removed` 与 `Retried`；`Box.DropFiles` 与 `FileDropState` 让页面声明接受系统文件拖放的区域，`ui.Configure` 先把文件交给该区域，再交给应用自己的 `OnFileDrop`，`ui.OpenFiles` 包装系统选择器，`FileRef.Path` 与 `ui.FilePath` 在平台有时给出文件路径。
- `ui/imagepreview` 在图片上打开预览对话框，带缩小、放大、适应与原始尺寸按钮，滚轮、`+`/`-`/`0` 与拖动平移都可用。
- `ui/mentions` 在输入触发字符后列出候选，方向键、Enter、Tab 与 Escape 操作，选中后替换掉键入的词而不把键盘从字段拿走。
- `ui/tour` 一次在一个控件旁显示一步说明并把窗口其余部分变暗，只有 Finish 算完成，找不到控件的步骤退化成普通说明；`ui/anchor` 是带当前章节标记的页内目录；`ui/comment` 排头像、作者、时间、正文、应用自己的操作按钮与嵌套回复。
- `ui/divider` 是中间或靠端带字的横线；`ui/typography` 把文本截断到指定的几行，需要时展开，并用新加的 `ui.SetClipboardText` 把全文复制到剪贴板。
- `ui/validate` 提供 `Required`、`MinLength`、`MaxLength`、`Min`、`Max`、`Pattern`、`Email`、`URL` 等带类型与自定义消息的规则，`Check` 取第一个失败，`Apply` 写进 `FormFieldState`；`ui.MaxLength(n)` 与 `ui.ShowCount()` 限制并显示文本字段的字符数。
- 进度可以画成环（`Box.Circle`）或分段（`Box.Segments`），并按 `Box.Status` 取成功、警告或危险色；`gfx.PathBuilder.Arc` 用三次曲线画圆弧。
- 按钮与开关都能进入忙碌态（`Box.Loading`），忙碌期间不上报也不响应按下，加载指示由页面作为 painter 提供，只用按钮不会把指示器链接进来。
- 滑块在轨道上放带文字的刻度（`Box.Marks`）；`Box.Warning` 让文本控件用警告色描边而不算校验失败；`ui.SelectGroups` 在选项列表里为每组加一行标题。
- `ui.Table` 的每个 `TableColumn` 自带 `Title` 与 `Sortable`；`TableSpec.Checked` 与 `Selection` 加一列勾选框与表头全选，`TableColumn.Filterable` 在表头给出筛选按钮并由 `Box.FilterClicked` 报告。
- 树的分支加载中可以用 `TreeNode.Loading` 把箭头换成指示器，这期间不响应按下，所以不会开始第二次请求。
- 文本字段的二次按下打开系统的剪切、复制、粘贴与全选菜单（macOS 与 Windows），命令与键盘快捷键走同一条路径，密码不会被复制；Linux 与只读字段由页面自己画同样的菜单，词表来自 `Config.TextMenu`，与 `PageConfig.EditMenu` 共用。
- `components` 的 toast 更紧凑，新增 `Toaster.Timeout`、`Toaster.Limit`、`ToastConfig{Action, Timeout, HideClose}`、`ShowConfig` 与 `ToastQueue.AddFor`，可以按窗口设策略、按条设动作与超时。
- `Config.Transparent` 直接声明透明窗口，`CapabilityTransparentWindow` 报告平台是否支持，`OnTransparentChange` 在窗口创建后告诉应用桌面是否真的透出来；Windows 用 DirectComposition 合成，Linux 的 X11 外壳在有合成管理器时也可透明。
- `app/systemauth` 用 Windows Hello 或 macOS 的 Touch ID／设备密码验证用户，`ContentWindow.SetConcealed` 在验证时盖住内容窗口。
- 文件可以从窗口拖到其他程序：`StartFileDrag` 拖已经存在的路径，`FilePromise` 与 `StartFilePromiseDrag` 拖在放下时才生成的内容，例如从远端服务器下载的文件；`base.DragState.OnMove` 让页面驱动的拖动越过窗口边界。
- `MenuItem.Toggled` 让菜单项切换设置而菜单保持打开；`OpenDirectoryOptions.InitialDirectory` 让原生文件夹选择器从指定目录开始；`WebView.ShowDevTools` 打开内嵌页面的开发者工具。
- 元素树可以做出入与移动动画：`Box.Pose` 用弹簧或曲线移动、缩放、旋转与淡出单个元素（`Pose.Rotate` 连文字一起转），`Box.Glide` 从上一帧的位置滑到新的布局位置，`Box.Presence` 让被移除的元素淡出，列表与树的 `Glide` 让键控的行滑到新位置。
- `gfx.SpringMotion` 是保留速度、可以在途中改目标的弹簧，`gfx.VelocityTracker`、`gfx.Project`、`gfx.Nearest`、`gfx.RubberBand` 与 `Canvas.Throw` 组成甩动、吸附与越界回弹，`gfx.RadiusOutset` 让外扩的焦点环与卡片在圆角为零时保持直角。
- `Surface.Pixel` 读取保留表面上一个点的蓝、绿、红与 alpha，以及它是否在图内；它只读已经保留的块，O(1) 且不分配，应用可以据此画出与底下像素反色的指针。
- Linux 剪贴板与选择：等待刚获得焦点的剪贴板所有者 (contributed by @szmcdull) (PR [#436](https://github.com/vivaui/viva/pull/436))；X11 选择等待被中断时重试，PRIMARY 与 AT-SPI 只复制选中的文本 (contributed by @caichangqing1120) (PR [#448](https://github.com/vivaui/viva/pull/448), [#433](https://github.com/vivaui/viva/pull/433), [#434](https://github.com/vivaui/viva/pull/434))。
- X11 文件拖放期间保留重绘 (contributed by @caichangqing1120) (PR [#447](https://github.com/vivaui/viva/pull/447))，GTK Wayland 在内容指针进入时保留预编辑 (contributed by @caichangqing1120) (PR [#421](https://github.com/vivaui/viva/pull/421))。
- macOS 在非主线程启动时立即失败而不是挂起 (contributed by @Ezreal-byte) (PR [#435](https://github.com/vivaui/viva/pull/435))；Windows 在读取 PNG 剪贴板失败时回退到 DIB (contributed by @DeanCen) (PR [#441](https://github.com/vivaui/viva/pull/441))。
- `textview` 在请求的滚动行于当前帧绘制 (contributed by @1lck) (PR [#450](https://github.com/vivaui/viva/pull/450))；文本域的自定义绘制保留选中文本 (contributed by @imjakey) (PR [#442](https://github.com/vivaui/viva/pull/442))。
- `dbusmenu` 首次读取构建的布局不再报告为变化。
- 更新后，安装器在 Windows 的「程序和功能」里写入新的版本与安装大小，包管理器不再反复提供同一个更新。
- `viva feed` 并行切更新补丁，`--patch-max-ratio` 可以丢弃大到不值得下载的补丁；`viva init` 的组件模板刷新；组件页面的 API 表格由 `api.json` 生成。
- headless 的 macOS 截图可以用 `VIVA_HEADLESS_METAL_DEVICE=low-power` 在双显卡的 Intel Mac 上使用集成显卡 (contributed by @shubo83) (PR [#437](https://github.com/vivaui/viva/pull/437))。

- `ui/steps`, `ui/descriptions`, `ui/timeline`, `ui/rate`, `ui/inputnumber`, `ui/datepicker`, `ui/timepicker` and `ui/transfer` are opt-in page packages built from the page's own primitives, so they follow the page's theme and density.
- `ui/alert`, `ui/tag` and `ui/result` report an outcome in the shared `ui.Status` vocabulary (default, success, warning, danger); `Theme.Warning` and `WarningColor` add the warning color, falling back to the danger color for a hand-built theme that leaves it zero.
- `ui/card` is a raised surface with an optional header (title, description and a slot at its end) and footer, a compact size and a flat form; `ui/empty` centers an icon, a title, a wrapping description and a slot for the next step.
- `ui/breadcrumb` makes each earlier place a link and `Max` folds the middle places behind an ellipsis menu; `ui/pagination` builds the page numbers, previous and next, total, page size and jump field from a total and a `State`.
- `ui/popconfirm` asks by a pressed button and reports `Confirmed` or `Cancelled` in the paint that delivers the press, with Escape and an outside press closing it without an answer; `ui/editabletabs` is a tab strip as wide as its titles with close and add buttons that scrolls and keeps the active tab in view.
- `ui/upload` is a drop area with the system picker button and one row per file with its status, progress, retry and remove; `Box.DropFiles` with a `FileDropState` declares an area that takes files dragged from the system, `ui.Configure` gives the window's `OnFileDrop` to that area before the application's own handler, `ui.OpenFiles` wraps the system picker, and `FileRef.Path` and `ui.FilePath` give a file's path where the platform has one.
- `ui/imagepreview` opens a preview dialog over a picture with zoom out, zoom in, fit and actual-size buttons, the wheel, `+`/`-`/`0` and drag to pan.
- `ui/mentions` lists matching options after a trigger character, driven by the arrow keys, Enter, Tab and Escape, and writes the chosen option in place of the typed word without taking the keyboard from the field.
- `ui/tour` shows one step beside one control with the rest of the window dimmed; only Finish counts as finishing, and a step whose control is absent is shown as a plain note. `ui/anchor` is an in-page table of contents with a rail marking the section in view, and `ui/comment` lays out an avatar, author, time, text, the page's own actions and nested replies.
- `ui/divider` is a rule with a label in the middle or near an end; `ui/typography` cuts text to the given number of lines, expands it on request, and copies the whole text with the new `ui.SetClipboardText`.
- `ui/validate` provides `Required`, `MinLength`, `MaxLength`, `Min`, `Max`, `Pattern`, `Email` and `URL` rules with caller-supplied messages, `Check` for the first failure and `Apply` to set a `FormFieldState`; `ui.MaxLength(n)` and `ui.ShowCount()` cap and show a text field's character count.
- A Progress draws as a ring (`Box.Circle`) or in segments (`Box.Segments`) and takes the success, warning or danger color from `Box.Status`; `gfx.PathBuilder.Arc` draws circular arcs as cubic curves.
- A Button and a Switch take a busy state (`Box.Loading`) that reports and answers no press while it is on, with the indicator supplied by the page as a painter so a plain button does not link it in.
- A Slider shows a dot and a word at each mark (`Box.Marks`); `Box.Warning` gives a text control a warning border without calling it invalid; `ui.SelectGroups` puts a heading row before each group of a Select's options.
- Each `TableColumn` of a `ui.Table` carries its own `Title` and `Sortable`; `TableSpec.Checked` with a `Selection` adds a column of checkboxes and a header checkbox, and `TableColumn.Filterable` adds a filter button to a heading that `Box.FilterClicked` reports.
- A tree branch whose children are loading shows `TreeNode.Loading` in place of its chevron and takes no press there, so a second press cannot start a second fetch.
- A secondary press on a text field opens the system's own Cut, Copy, Paste and Select All menu on macOS and Windows, with each command on the same path as its keyboard chord and a secret never cut or copied; Linux and read-only fields draw the same menu in the page, with the words from `Config.TextMenu`, shared with `PageConfig.EditMenu`.
- The `components` toast is more compact, and `Toaster.Timeout`, `Toaster.Limit`, `ToastConfig{Action, Timeout, HideClose}`, `ShowConfig` and `ToastQueue.AddFor` set the policy for a window and the action and timeout for one toast.
- `Config.Transparent` names the request for a transparent window, `CapabilityTransparentWindow` reports whether the platform has one, and `OnTransparentChange` tells the application once the window exists whether the desktop shows through it; Windows composites it with DirectComposition, and the X11 shell on Linux does too where a compositing manager owns the screen.
- `app/systemauth` verifies the user with Windows Hello or macOS Touch ID and the device password, and `ContentWindow.SetConcealed` conceals an application's content windows while it does.
- Files drag out of a window: `StartFileDrag` takes paths that exist, and `FilePromise` with `StartFilePromiseDrag` takes files the application produces when the target asks, such as one downloaded from a remote server; `base.DragState.OnMove` lets a page-driven drag continue past the window.
- `MenuItem.Toggled` changes a setting without closing the menu, `OpenDirectoryOptions.InitialDirectory` starts a native folder picker in a given folder, and `WebView.ShowDevTools` opens the developer tools of an embedded page.
- The element tree animates entrances, exits and moves: `Box.Pose` moves, scales, turns and fades one element about its centre with a spring or a curve (`Pose.Rotate` turns its text too), `Box.Glide` slides an element from where the last frame painted it to where the layout now puts it, `Box.Presence` fades a removed element out, and `Glide` on a list or tree slides its keyed rows to their new places.
- `gfx.SpringMotion` is a closed-form spring that keeps its velocity when the target changes on the way; `gfx.VelocityTracker`, `gfx.Project`, `gfx.Nearest`, `gfx.RubberBand` and `Canvas.Throw` give a drag its release speed, snap point and pull past a range; and `gfx.RadiusOutset` keeps outset focus rings and cards square when the radius is zero.
- `Surface.Pixel` reads one point of a retained surface as blue, green, red and alpha, and whether the point is inside it; it reads the retained tiles in O(1) without allocating, so an application can draw a pointer that inverts the pixels under it.
- Linux clipboard and selection: the clipboard owner is waited for just after focus (contributed by @szmcdull) (PR [#436](https://github.com/vivaui/viva/pull/436)), an interrupted X11 selection wait is retried, and X11 PRIMARY and AT-SPI copy only the selected text (contributed by @caichangqing1120) (PR [#448](https://github.com/vivaui/viva/pull/448), [#433](https://github.com/vivaui/viva/pull/433), [#434](https://github.com/vivaui/viva/pull/434)).
- An X11 file drop keeps its redraws (contributed by @caichangqing1120) (PR [#447](https://github.com/vivaui/viva/pull/447)), and the GTK Wayland preedit survives the content pointer entering (contributed by @caichangqing1120) (PR [#421](https://github.com/vivaui/viva/pull/421)).
- macOS fails fast when started off the main thread instead of hanging (contributed by @Ezreal-byte) (PR [#435](https://github.com/vivaui/viva/pull/435)), and Windows falls back to DIB when the PNG clipboard read fails (contributed by @DeanCen) (PR [#441](https://github.com/vivaui/viva/pull/441)).
- `textview` paints the requested scroll line in the current frame (contributed by @1lck) (PR [#450](https://github.com/vivaui/viva/pull/450)), and a textarea's custom painter covers its selected text (contributed by @imjakey) (PR [#442](https://github.com/vivaui/viva/pull/442)).
- `dbusmenu` no longer announces the layout its own first read builds.
- After a payload update the installer writes the new version and size into Windows' Add or Remove Programs entry, so a package manager stops offering the same update again.
- `viva feed` cuts update patches in parallel and `--patch-max-ratio` drops a patch too large to be worth downloading; `viva init`'s component templates are refreshed; every component page's API tables are generated from `api.json`.
- Headless screenshots on macOS can use the integrated GPU of a dual-GPU Intel Mac with `VIVA_HEADLESS_METAL_DEVICE=low-power` (contributed by @shubo83) (PR [#437](https://github.com/vivaui/viva/pull/437)).

## 注意 · Caveats

- `TableSpec.Headers` 与 `TableSpec.Sortable` 移除，改为每个 `TableColumn` 的 `Title` 与 `Sortable`；没有任何列带 `Title` 的表格不再画表头，`Headers` 与空 `Columns` 共享宽度的写法要改成每列一个 `TableColumn`。
- `TextFieldID`、`TextAreaID`、`RadioID`、`SelectID` 与 `ColorPickerID` 移除，身份改为写在固定参数末尾的 `ui.WithID(id)`；`PopoverWith` 改名为 `ui.Popover`、`ModalWith` 改名为 `ui.Modal`，spec 放在 body 之前，零值 `PopoverSpec` 居中而不是对齐起始边。
- `app.StartFileDrag` 不再返回目标接受的效果：Windows 的拖动阻塞到放下才返回，macOS 与 Linux 在拖动进行时就返回。
- `ui.Configure` 现在把窗口的文件拖放先交给页面声明的 `Box.DropFiles` 区域；只设自己的 `OnFileDrop`、没有声明区域的程序看到的事件与以前相同。
- 细则见 [升级指南 / Upgrading](../upgrading.md#v069---identity-options-and-required-specs)。

- `TableSpec.Headers` and `TableSpec.Sortable` are removed; each `TableColumn` has a `Title` and a `Sortable` instead. A table none of whose columns has a `Title` draws no header row, and a table that shared its width between `Headers` and no `Columns` writes one `TableColumn` per column.
- `TextFieldID`, `TextAreaID`, `RadioID`, `SelectID` and `ColorPickerID` are removed: the identity is the `ui.WithID(id)` option at the end of the fixed arguments. `PopoverWith` is now `ui.Popover` and `ModalWith` is now `ui.Modal`, taking their spec before the body, and a zero `PopoverSpec` centers the popover instead of lining it up with the anchor's start.
- `app.StartFileDrag` no longer reports the effect the target took: the Windows drag blocks until the drop, while macOS and Linux return once the drag is running.
- `ui.Configure` now gives the window's file drop to a page's `Box.DropFiles` area first; an application that sets its own `OnFileDrop` and declares no area sees the same events as before.
- Details are in the [upgrading guide](../upgrading.md#v069---identity-options-and-required-specs).
