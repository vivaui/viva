v0.6.8 comes after v0.6.7: `ui.Run` takes a `PageConfig` as `OpenWindow` does, and the release adds touch input, bidirectional text carets and CodeEditor decorations, a read-only selectable `textview`, a link graph, responsive layout and delayed posting, with many input-method, clipboard and performance fixes on Linux, Windows and macOS. macOS is the reference platform.

## 拿到它 · Getting it

`go get github.com/vivaui/viva@v0.6.8`，需要 Go 1.26 或更新；系统依赖与 v0.6.7 相同。每个 Release 附带 `viva` 命令的预编译压缩包、`SHA256SUMS`，以及 Homebrew 与 Scoop 清单（`brew install vivaui/tap/viva`，或 `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` 后 `scoop install viva`）。

## 有什么 · What is in it

- `ui.Run(config, ui.PageConfig{View: m.page})`：一个窗口的程序可以在同一个 `PageConfig` 里设置主题和样式；`ui` 重新导出了自定义控件与绘制要用的类型（`Identity`、事件与画布类型、字重、阴影层级、文本方向与对齐、`ButtonVariant`、`TableColumn`、各控件的外观）。
- `Box.Variant` 可以在运行时选择按钮变体；`ui.Table` 现在自己完整：页面把移动选中行的按键送给它，点击选中一行，`TableState.Changed` 报告选择变化，只给 `Headers` 时各列均分宽度。
- `ui.AlertDialog` 与 `Modal` 一样开在 `*bool` 上，并报告确认动作；`ui.MenuAt` 相对应用自绘表面的矩形打开菜单；没有指定初始焦点的 `Dialog` 把键盘交给正文的第一个控件；`FormField` 的标题像 HTML label 一样标注它的第一个控件。
- `Box.From` 与 `Container`、`Breakpoint` 让布局随窗口或容器宽度变化，`Box.Hide`、`Box.Show` 隐藏和重新显示元素，`Box.Maxs`、`Box.Italic`、`Box.Strike`、`Box.OverflowWrap` 补全文本与尺寸属性，长单词在没有空间时可以折断。
- `ui/textview` 是只读、可选择、可复制的文本；`ui.TextFieldID` 也能编辑模型里的字符串；输入、分割条、提示和树控件补全了几处缺口。
- `components` 新增力导向的链接图（`PaintGraph`、`GraphState`、`GraphSim`），CodeEditor 增加行号栏、字节范围装饰与下划线，保持双向文本的成形光标位置，只重排被编辑触及的行；下拉菜单可以设置行高与最大宽度；Select 与 Combobox 的列表按弹出规则定位。
- `app.Invalidator.Post` 让 goroutine 把结果交回窗口，`Application.PostAfter` 在事件循环上延时执行；`Config.Maximized` 以最大化打开窗口，`Config.OnDeactivate` 报告窗口失去激活，`Config.CaptureMenuKeys` 让应用先于菜单取键。
- `app.WindowNotification` 是可点击的通知弹窗；`app.SetClipboardImage` 把图片放上剪贴板；`WebViewConfig` 增加 `Partition`、`UserAgentSuffix` 和 `OnProcessFailed`，`WebView.IsCrashed` 与 `ProcessFailure` 报告页面进程的死亡。
- 触摸：手指读作点击、拖动、甩动与长按，滚动可以越过末端并弹回，小于 44 px 的控件也能被手指点中，`Config.OnPinch` 报告双指缩放，轻点放置光标、按住选词、按住显示提示；Windows 按触摸指针读手指，Linux X11 按 X Input 触摸事件读手指。
- `Canvas.TitlebarInsets` 与 `ui.C.TitlebarInsets` 给出本窗口的标题栏边距：自定义标题栏时是平台的窗口按钮，全屏或系统标题栏下为零。
- `Theme.WithTextScale` 按偏好缩放字号与行高，`Theme.TooltipDelay` 设置提示延迟，`gfx.TextHit` 返回点击所在的簇边缘，完全透明的文本不再绘制。
- 辅助技术：Linux 上新增的无障碍控件会发出焦点通知；X11 上剪贴板变化会通知、按 TARGETS 读取并刷新过期的所有权，Fcitx 4 取消预编辑时保留选中文本，GTK 在窗口失焦时丢弃未选中的预编辑，IBus 先从 `WAYLAND_DISPLAY` 找守护进程地址。
- Windows 上菜单捕获按键时保持输入法组合，最小化的窗口不再报告为窗口位置。
- X11 窗口不用等输入就能绘制，重新曝光后会重绘；所有窗口共用一个 Vulkan 设备，标签图像从块里子分配，上传经保留的缓冲区，不再让 GPU 空等。
- 编辑器的文本以 UTF-8 叶子保存，点击与选词不再扫描整行，Textarea 只排版视口内的行且只重排被编辑的段落，CodeEditor 只排版被编辑触及的行；`textarea` 跟随程序修改。
- 通知窗口会保持在屏幕内并可以移动，`Select` 在对话框、抽屉或弹出层里不再替外层结束出现动画，面板的滚轮事件不再传给下面的页面，`Markdown` 解码行内字符引用，PAC 求值在取消时被唤醒而不是轮询。
- 打包 `.dmg` 时等待磁盘映像服务放手、在卷已卸载或仍挂载时都能分离，映像构建过程中不会暴露可安装的应用。

- `ui.Run(config, ui.PageConfig{View: m.page})`: a one-window program sets its theme and styles in the same `PageConfig`; `ui` re-exports the types a custom control and a draw take (`Identity`, the event and canvas types, font weights, shadow levels, text direction and alignment, `ButtonVariant`, `TableColumn`, and the control looks).
- `Box.Variant` chooses a button's variant at run time; `ui.Table` is whole as declared: the page routes it the keys that move its selection, a click selects a row, `TableState.Changed` reports the change, and `Headers` without `Columns` share the width.
- `ui.AlertDialog` opens on a `*bool` as `Modal` does and reports the confirming action; `ui.MenuAt` opens a menu against a rectangle of the application's own surface; a `Dialog` that names no initial focus gives the keyboard to the first control of its body; a `FormField` title labels its first control as an HTML label does.
- `Box.From` with `Container` and `Breakpoint` lays out by the window's or a container's width, `Box.Hide` and `Box.Show` hide and show an element, `Box.Maxs`, `Box.Italic`, `Box.Strike` and `Box.OverflowWrap` complete the text and size attributes, and a long word breaks when the box has no room.
- `ui/textview` is read-only text that selects and copies; `ui.TextFieldID` also edits a model string; fields, the splitter, tooltips and trees close several gaps.
- `components` adds a force-directed link graph (`PaintGraph`, `GraphState`, `GraphSim`), and CodeEditor gains a gutter, byte-range decorations and underlines, keeps shaped bidirectional caret placement, and lays out only the lines an edit touched; dropdown menus take a row height and a maximum width; Select and Combobox lists are placed by the popup rule.
- `app.Invalidator.Post` hands a goroutine's result to a window and `Application.PostAfter` runs delayed work on the event loop; `Config.Maximized` opens a window maximized, `Config.OnDeactivate` reports a window losing the activation, and `Config.CaptureMenuKeys` lets an application take keys before the menu.
- `app.WindowNotification` is a clickable notification popup; `app.SetClipboardImage` puts an image on the clipboard; `WebViewConfig` adds `Partition`, `UserAgentSuffix` and `OnProcessFailed`, and `WebView.IsCrashed` and `ProcessFailure` report the death of a page's process.
- Touch: fingers read as taps, pans, flings and long presses, scrolling carries past its end and springs back, a fingertip reaches controls smaller than 44 px, `Config.OnPinch` reports two-finger pinches, a tap places the caret, a held finger selects a word or opens a tooltip; Windows reads a finger as a touch pointer and Linux X11 reads X Input touch events.
- `Canvas.TitlebarInsets` and `ui.C.TitlebarInsets` give the titlebar insets of the window being painted: the platform's buttons for a custom titlebar, none in full screen or under a system titlebar.
- `Theme.WithTextScale` scales text size and line height by a preference, `Theme.TooltipDelay` sets the tooltip delay, `gfx.TextHit` returns the cluster edge a click hits, and fully transparent text draws nothing.
- Platform input: newly added accessibility controls announce focus on Linux; on X11 clipboard changes notify and the clipboard is read by TARGETS with stale ownership refreshed, Fcitx 4 keeps selected text when its preedit is cancelled, GTK drops an unselected preedit on focus loss, and IBus finds the daemon address from `WAYLAND_DISPLAY` first.
- On Windows IME composition survives a menu that captures keys, and a minimized frame is no longer reported as the window position.
- X11 windows paint without waiting for input and after a re-expose; every window shares one Vulkan device, label image memory is sub-allocated from blocks, and uploads go through kept buffers without idling the GPU.
- The editor keeps its text as UTF-8 leaves, a click or word selection no longer scans the line, Textarea lays out only the rows in view and rewraps only the paragraphs an edit changed, CodeEditor lays out only the lines an edit touched, and a textarea follows program edits.
- The notification window stays on screen and can move, a `Select` inside a dialog, drawer or popover no longer closes the enclosing presence in its place, panel wheel events stay off the page underneath, `Markdown` decodes inline character references, and PAC evaluation wakes on cancel instead of polling.
- Packaging a `.dmg` waits until the disk image service lets go, detaches whether the volume is already unmounted or still attached, and keeps an image build from exposing an installable app.

## 注意 · Caveats

- `ui.Run(config, m.page)` 现在是 `ui.Run(config, ui.PageConfig{View: m.page})`。按 `main` 上 v0.6.8 之前的指南写出的程序在 v0.6.7 上无法编译，原因就是这一处；升到 v0.6.8 后指南与代码一致。
- `app.TitlebarInsets()` 已移除，在页面里用 `c.TitlebarInsets()`，在自绘代码里用 `Canvas.TitlebarInsets`。
- `ui.AlertDialog(c, spec)` 现在是 `ui.AlertDialog(c, &open, spec)` 并返回确认结果；`PopoverWith` 的 `*bool` 移到了 spec 之前；`base` 包同步变化。`ui.TextFieldID` 变为泛型，按值取用该函数的代码要写类型实参。
- `Box.Variant` 选的按钮变体互不叠加：指南里的 `Ghost().Destructive()` 以前是实心红色按钮，现在是带危险色的幽灵按钮。
- dev 构建会拒绝没有 `Columns` 也没有 `Headers` 的 `Table`，它以前什么也不画。
- Android 与 iOS 后端不在 Viva 主分支上，它们留在 `mobile` 分支；桌面上的触摸、手指滚动、捏合与触摸提示都在本版本里。
- 细则见 [升级指南 / Upgrading](../upgrading.md#v068---uirun-takes-a-pageconfig-and-four-more-signatures)。

- `ui.Run(config, m.page)` is now `ui.Run(config, ui.PageConfig{View: m.page})`. A program written from the guides on `main` before v0.6.8 does not compile against v0.6.7 for this reason alone; with v0.6.8 the guides and the code agree.
- `app.TitlebarInsets()` is removed: use `c.TitlebarInsets()` in a page and `Canvas.TitlebarInsets` in custom painting.
- `ui.AlertDialog(c, spec)` is now `ui.AlertDialog(c, &open, spec)` and returns the confirmation; `PopoverWith` takes its `*bool` before the spec; the `base` package changes alike. `ui.TextFieldID` is now generic, so code taking the function as a value must name a type argument.
- Button variants chosen with `Box.Variant` do not combine: the guide's `Ghost().Destructive()` used to be a solid red button and is now a ghost with the danger color.
- A dev build stops a `Table` with neither `Columns` nor `Headers`, which painted nothing before.
- The Android and iOS backends are not on Viva's main branch; they continue on the `mobile` branch. Desktop touch, finger scrolling, pinch and touch tooltips are in this release.
- Details are in the [upgrading guide](../upgrading.md#v068---uirun-takes-a-pageconfig-and-four-more-signatures).
