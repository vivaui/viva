v0.2.3 是 v0.2.2 之后的 patch 版本：公开 API 只有新增，没有删除或改签名，升级不需要改调用点。本版带来单个控件自己的圆角与字号、Windows 的原生窗口材质、用应用自己画的图片作系统指针、剪贴板变化通知和窗口接管系统快捷键，并修掉图标编译、终端单元格像素与 Windows 窗口位置的问题。macOS 是参考平台。

v0.2.3 is a patch release after v0.2.2: the public API only gains members, with no removal or signature change, so upgrading needs no call-site edits. It brings a corner radius and font size for one control, native window materials on Windows, an application's own picture as the system pointer, clipboard change notifications and a window that takes the system's shortcuts, and fixes icon compilation, terminal cell pixels and remembered window positions on Windows. macOS is the reference platform.

## 拿到它 · Getting it

`go get github.com/vivaui/viva@v0.2.3`，需要 Go 1.26 或更新；系统依赖与 v0.2.2 相同，只有显示系统网页的应用需要对应的网页组件，只有选用 GTK 外壳（`-tags vivagtk`）的应用需要系统的 GTK 3。每个 Release 附带 `viva` 命令的预编译压缩包、`SHA256SUMS`，以及 Homebrew 与 Scoop 清单（`brew install vivaui/tap/viva`，或 `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` 后 `scoop install viva`）；压缩包没有代码签名或公证，浏览器下载的 macOS 版会被 Gatekeeper 拦下，brew、curl 与 `go install` 不受影响。

`go get github.com/vivaui/viva@v0.2.3` needs Go 1.26 or newer; the system requirements are those of v0.2.2, and only an application that shows web pages needs the matching web component and only one that opts into the GTK shell (`-tags vivagtk`) needs the system's GTK 3. Every Release carries prebuilt archives of the `viva` command, `SHA256SUMS`, and Homebrew and Scoop manifests (`brew install vivaui/tap/viva`, or `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` then `scoop install viva`); the archives are not code-signed or notarized, so a browser download on macOS is stopped by Gatekeeper while brew, curl and `go install` are not affected.

## 有什么 · What is in it

- 新增 `ui.Theme.WithRadius`、`WithFontSize` 与 `WithControlHeight`，给一个控件自己的圆角、字号与高度，同一主题下的其它控件不受影响
- flex 页面里控件的 `Radius` 与 `FontSize` 现在只作用于该控件，可以写 `f.Input(s).Radius(ui.RadiusFull).FontSize(16)`，其中 `ui.RadiusFull` 把形状画成胶囊
- `components.Button` 新增 `Height`，flex 的 `Button` 设了高度就按这个高度绘制，不再只是占住空间
- 新增 `flex.Frame.Bounds`，页面内的自定义绘制在 `End` 之前就知道自己所在的区域
- 新增 `app.OnClipboardChange`，系统剪贴板（包括其它应用写入）变化时收到回调，没有注册时不动用定时器、线程或轮询 (contributed by @o3ku) (PR [#90](https://github.com/vivaui/viva/pull/90))
- 新增 `ui.CursorImage` 与 `app.SetCursorImage`，把应用自己画的图片作为系统指针，随鼠标移动也显示在窗口的边缘之上
- 新增 `ui.PointerCursorHidden` 与 `app.CursorHidden`，完全隐藏系统指针，供自己画指针的界面使用 (contributed by @o3ku) (PR [#89](https://github.com/vivaui/viva/pull/89))
- 新增 `app.Config.WindowBackdrop`、`app.BackdropStyle` 与 `app.Config.OnBackdropChange`，在 Windows 上选用 Mica、Mica Alt 与 Acrylic 原生窗口材质，其中 Mica 与 Mica Alt 需要 Windows 11 22H2 或更新 (contributed by @Yuch3nE) (PR [#85](https://github.com/vivaui/viva/pull/85))
- 新增 `ui.Canvas.RoundedOutline`，在透明填充上描边而不透出实心底
- 新增 `app.Window.CaptureSystemShortcuts`，窗口获得焦点时接管 Windows 键组合、Alt+Tab、Alt+Esc 与 Ctrl+Esc，Windows 之外的平台返回 `ErrUnsupported`
- `viva` 的图标编译器支持 `<ellipse>`，不认识的元素现在让编译失败而不是被静默跳过
- 在知道缩放比的画布上，终端单元格宽度取整到设备像素，相邻单元格不再共用一列像素，框线与 powerline 箭头不会被后画的颜色覆盖
- 修复 macOS 在没有事件循环的进程里启动或停止剪贴板监听会阻塞主线程
- 修复 Windows 上被记住位置的多显示器窗口可能整块落在屏幕外，现在至少留一条可以抓取的边 (contributed by @yiqiui) (PR [#88](https://github.com/vivaui/viva/pull/88))

- New `ui.Theme.WithRadius`, `WithFontSize` and `WithControlHeight` give one control its own corner radius, font size and height, leaving the other controls on the same theme as they were
- `Radius` and `FontSize` on a control in a flex page now apply to that control alone, as in `f.Input(s).Radius(ui.RadiusFull).FontSize(16)`, with `ui.RadiusFull` drawing the shape as a pill
- `components.Button` gains `Height`, and a flex `Button` given one is painted that tall instead of only taking the room
- New `flex.Frame.Bounds` tells custom painting inside a page the region it belongs to before `End`
- New `app.OnClipboardChange` calls back when the system clipboard changes, including from another application, and starts no timer, thread or poll until it is registered (contributed by @o3ku) (PR [#90](https://github.com/vivaui/viva/pull/90))
- New `ui.CursorImage` and `app.SetCursorImage` show a picture the application painted as the system pointer, which follows the mouse and shows over the window's edges
- New `ui.PointerCursorHidden` and `app.CursorHidden` remove the system pointer entirely for a surface that draws its own (contributed by @o3ku) (PR [#89](https://github.com/vivaui/viva/pull/89))
- New `app.Config.WindowBackdrop`, `app.BackdropStyle` and `app.Config.OnBackdropChange` select the Mica, Mica Alt and Acrylic native window materials on Windows, with Mica and Mica Alt needing Windows 11 22H2 or later (contributed by @Yuch3nE) (PR [#85](https://github.com/vivaui/viva/pull/85))
- New `ui.Canvas.RoundedOutline` strokes inside a rectangle without painting its interior, for outlines over translucent fills
- New `app.Window.CaptureSystemShortcuts` hands a focused window the Windows key and its chords, Alt+Tab, Alt+Esc and Ctrl+Esc, and other platforms return `ErrUnsupported`
- The `viva` icon compiler compiles `<ellipse>`, and an element it does not know now fails the compile instead of being silently skipped
- On a canvas that knows its display scale a terminal cell is a whole number of device pixels wide, so neighbouring cells no longer share a pixel column and box-drawing lines and powerline arrows keep their color
- Fixed starting or stopping the clipboard watch on macOS blocking the main thread in a process that runs no event loop
- Fixed a remembered window position on Windows leaving a multi-monitor window entirely off screen, which now keeps a strip that can be grabbed (contributed by @yiqiui) (PR [#88](https://github.com/vivaui/viva/pull/88))

## 注意 · Caveats

没有公开 API 被删除或改签名（用 `apidiff` 对比 v0.2.2 的公开包，只有新增），升级不需要改调用点；按 1.0 之前的语义新增 API 通常进 minor，这次与 v0.2.2 一样按 patch 发布，是因为没有破坏性变更。有四处行为变化值得知道：

- flex 控件上的 `Radius` 与 `FontSize` 此前被静默忽略，现在生效，设置过它们的页面会按新值绘制
- `ui.Canvas.MonoCellSize` 在知道缩放比的画布上返回取整到设备像素的宽度，用它的值算出的列位置会略有变化
- 图标编译器现在对不认识的元素报错，含这类元素的图标此前会静默编译成残缺图形
- macOS 上注册 `app.OnClipboardChange` 后每 250 ms 读一次剪贴板的变更计数，注销后停止

No public API is removed and no signature changes (comparing the public packages with v0.2.2 using `apidiff` shows additions only), so upgrading needs no call-site edits; by pre-1.0 semantics new API usually lands in a minor release, and like v0.2.2 this ships as a patch because nothing breaks. Four behaviors are worth knowing:

- `Radius` and `FontSize` on a flex control were silently ignored and now take effect, so a page that set them paints with the values it asked for
- `ui.Canvas.MonoCellSize` returns a width rounded to whole device pixels on a canvas that knows its scale, so column positions computed from it shift slightly
- The icon compiler now reports an element it does not know, where an icon containing one used to compile silently into an incomplete glyph
- Registering `app.OnClipboardChange` on macOS reads the pasteboard's change count every 250 ms, and stops when it is unregistered
