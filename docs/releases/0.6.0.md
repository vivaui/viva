v0.6.0 是 v0.5.1 之后的 minor 版本：Page 成为唯一的公开界面编写模型，`ui.Frame` 与 `ui.View` 不再导出，旧的 View 宿主拖动 API 也移除了，所以升级需要改调用点，迁移方式写在文末。本版同时带来页面浮层、声明式表单字段、页面级拖放与 part 拖动、列表/树/滚动/对话框/弹出层的页面 API、Flow 与横向滚动、字符网格的等宽字形，以及 Windows 输入法与嵌入视图的一批修复。macOS 是参考平台。

v0.6.0 is a minor release after v0.5.1: Page is now the only public authoring model. `ui.Frame` and `ui.View` are no longer exported and the old View-only drag host API is gone, so upgrading needs call-site changes; the migration is at the end of these notes. The release also brings page overlays, declarative form fields, page-level drag and drop and part drag, page APIs for lists, trees, scrolling, dialogs and popovers, Flow and sideways scrolling, character-cell monospace glyphs, and a set of Windows input-method and embedded-view fixes. macOS is the reference platform.

## 拿到它 · Getting it

`go get github.com/vivaui/viva@v0.6.0`，需要 Go 1.26 或更新；系统依赖与 v0.5.1 相同。每个 Release 附带 `viva` 命令的预编译压缩包、`SHA256SUMS`，以及 Homebrew 与 Scoop 清单（`brew install vivaui/tap/viva`，或 `scoop bucket add vivaui https://github.com/vivaui/homebrew-tap` 后 `scoop install viva`）；压缩包没有代码签名或公证，浏览器下载的 macOS 版会被 Gatekeeper 拦下，brew、curl 与 `go install` 不受影响。

`go get github.com/vivaui/viva@v0.6.0` needs Go 1.26 or newer; the system requirements are those of v0.5.1. ## 有什么 · What is in it

- Page 成为唯一的公开编写模型：应用和组件都是 `func(c ui.C)`，用 `ui.Row(c)`、`ui.Text(c, ...)`、`ui.List(c, ...)` 等声明；`ui.Frame`、`ui.View` 和只服务于 View 的 `ui.Drag`、`DragState.Pointer`、`DragState.Key` 不再导出
- 为嵌入区域的 Page 增加 `Page.Key` 与 `Page.Pointer`，和已有的 `Page.Wheel`、`Page.TextInput` 一起让宿主把真实输入路由给页面；整窗页面仍由 `Page.Config` 接线
- 新增 `ui.Overlay` 与 `ui.Band`（`LayerContent`、`LayerPaneChrome`、`LayerDrag`）：应用自己的浮层落在页面与 Viva 菜单/对话框之间，命中与 Tab 顺序随层变化
- 新增 `ui.FormField`、`ui.FormFieldState` 和公开的 `field` 包：标题、控件槽位与 BeginField 同一节奏，不绑定值、不裁剪弹出层
- 新增页面级拖放：`Box.DragSource`/`DropTarget` 与 `DrawContext.DragSource`/`DropTarget`，支持控件自行绘制的 part；`DragState` 仍负责按下、阈值、目标与释放
- 新增 `ui.Flow`：会换行的 Row，`LineGap` 控制行距；新增 `Scroll.Sideways`、`Scroll.Scrollbars` 与 `ScrollState.Pinned`、`MaxX`、`ScrollToX`，支持横向滚动、可见滚动条和预布局虚拟化
- 页面列表、树、表格、标签页、选择器、滑块、分割器、对话框、弹出层、抽屉和 Toast 都可用 `ui.C`/`ui.Box` 声明；列表和树公开行身份、行高、吸顶标题、拖动排序、typeahead 与横向滚动
- 新增 `ui.Control`/`ui.Handlers`、`ui.CustomLayout`、焦点绑定、值 Memo、绘制句柄与页面作用域 Effect；对话框增加标题栏槽位，Popover 增加标题、描述和页面弹层高度
- 新增页面级 Padding/Margin 单边设置、PopupLayer、页面菜单项、Toast 操作按钮和 Drawer 滑动关闭
- gfx 的等宽排版改为按字体自身的格子度量，新增制表符图形、方块图形、盲文与几何形状的单元格绘制；修复图标缓存键、嵌入视图阴影与点击、Direct2D 中等/半粗等宽字形
- app 允许 Windows 文本输入禁用宿主 IME，延迟计算复制覆盖值；修复按键关闭浮层时多发布一帧，以及 `ScrollAt` 区域的滚轮归属
- 修复事件遍历中的焦点请求与按键路由循环，让焦点在同一次事件中送达；修复列表滚动请求在后续绘制中结算；新增顺序 Effect 和带 key 的运行；headless driver 在第一帧前绑定 invalidator
- 新增跨版本升级指南 `docs/upgrading.md`，并补充 `MarkedSelection` 是 `Text` 中范围的文档

- Page becomes the only public authoring model: applications and components are `func(c ui.C)`, declaring with `ui.Row(c)`, `ui.Text(c, ...)`, `ui.List(c, ...)` and the rest; `ui.Frame`, `ui.View` and the View-only `ui.Drag`, `DragState.Pointer` and `DragState.Key` are no longer exported
- New `Page.Key` and `Page.Pointer` route real input to a page drawn into a region, alongside the existing `Page.Wheel` and `Page.TextInput`; a whole-window page still wires them with `Page.Config`
- New `ui.Overlay` and `ui.Band` (`LayerContent`, `LayerPaneChrome`, `LayerDrag`): an application's own overlay sits between the page and Viva's menus and dialogs, with hits and Tab order following the band
- New `ui.FormField`, `ui.FormFieldState` and the public `field` package: a title and one control slot at the rhythm of BeginField, binding no value and clipping no popup
- New page-level drag and drop: `Box.DragSource`/`DropTarget` and `DrawContext.DragSource`/`DropTarget` for parts a control paints itself; `DragState` still owns the press, threshold, target and release
- New `ui.Flow`, a Row that wraps, with `LineGap` between lines; new `Scroll.Sideways`, `Scroll.Scrollbars` and `ScrollState.Pinned`, `MaxX` and `ScrollToX` for horizontal scrolling, visible scrollbars and pre-layout virtualization
- Page lists, trees, tables, tabs, selectors, sliders, splitters, dialogs, popovers, drawers and Toasts are declared with `ui.C`/`ui.Box`; lists and trees expose row identities and heights, pinned section headings, row reordering, typeahead and sideways scrolling
- New `ui.Control`/`ui.Handlers`, `ui.CustomLayout`, focus bindings, value Memos, paint handles and page-scoped Effects; dialogs gain a header slot, and Popovers gain a title, description and page popup layer
- New one-side page Padding/Margin, PopupLayer, page menu items, Toast action buttons and swipe-to-close Drawers
- gfx lays out monospace text on the font's own cells and draws tab, block, braille and geometric shapes as cell geometry; fixes the icon cache key, embedded-view shadows and clicks, and Direct2D medium/semibold monospace runs
- app lets a Windows text input disable the host IME and evaluates copy overrides lazily; fixes an extra frame when a key closes an overlay and wheel routing for `ScrollAt` areas
- Fixes focus requests and key routing loops during an event pass, settles List scroll requests over the following paints, adds sequential and keyed Effects, and binds the headless driver's invalidator before its first frame
- Adds the cross-release upgrade guide `docs/upgrading.md` and documents `MarkedSelection` as a range into `Text`

## 迁移 · Migration

- 应用入口继续用 `ui.Run(config, page)` 或 `ui.NewPage(ui.PageConfig{View: page})`；`PageConfig.View` 是声明函数，不是已移除的 `ui.View` 类型
- 把 `ui.View.Draw(canvas, ..., func(f *ui.Frame) { ... })` 改成 `ui.Page.Draw(canvas, bounds, func(c ui.C) { ... })`，把 `f.Row()`/`f.Text()` 等改成 `ui.Row(c)`/`ui.Text(c, ...)`
- 组件写成 `func(c ui.C) ui.Box`；需要自己绘制的控件用 `ui.Control` 和 `ui.Handlers`，自定义布局用 `ui.CustomLayout`
- 嵌入的 Page 由宿主把事件交给 `Page.Key`、`Page.Pointer`、`Page.Wheel` 与 `Page.TextInput`；不要把旧的 `ui.Drag` 或 View 宿主接线搬回来
- 页面拖动改用 `DragSource`/`DropTarget`；控件内部画出的 part 用 `DrawContext` 的同名方法
- 应用和组件的测试通过公开 Page API 驱动；Viva 自己的引擎测试使用包内 test-only alias，不构成公开兼容层

- Application entry points stay `ui.Run(config, page)` or `ui.NewPage(ui.PageConfig{View: page})`; `PageConfig.View` is the declaration function, not the removed `ui.View` type
- Replace `ui.View.Draw(canvas, ..., func(f *ui.Frame) { ... })` with `ui.Page.Draw(canvas, bounds, func(c ui.C) { ... })`, and `f.Row()`/`f.Text()` and the rest with `ui.Row(c)`/`ui.Text(c, ...)`
- Write components as `func(c ui.C) ui.Box`; a custom painted control uses `ui.Control` and `ui.Handlers`, a custom layout uses `ui.CustomLayout`
- A host of an embedded Page gives its events to `Page.Key`, `Page.Pointer`, `Page.Wheel` and `Page.TextInput`; do not reintroduce the old `ui.Drag` or View host wiring
- Page drag and drop uses `DragSource`/`DropTarget`; a part a control paints uses the same methods on `DrawContext`
- Application and component tests drive the public Page API; Viva's own engine tests use package-local test-only aliases, which are not a public compatibility layer
